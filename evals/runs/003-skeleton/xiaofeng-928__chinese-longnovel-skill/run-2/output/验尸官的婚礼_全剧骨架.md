# 《验尸官的婚礼》全剧骨架

60 集竖屏短剧 · 每集 1–2 分钟 · AI 拍摄
分集大纲和剧本以本骨架为准，不得改动底牌、揭示顺序和人物退场。

---

## 一、总纲

**主问题**：三年前是谁杀了沈峥。
**暗线**：林晚自己签的那份“意外”报告。她每赢一局，真相和她的签名都近一步，最后她得亲手推翻自己。

**单集公式**（每集都要有）：
1. 一样能给特写的证据（疤、切片、照片、录音、袖扣）；
2. 沈家或周启年出手毁证、抹黑；
3. 林晚用专业反打，当场赢；
4. 集尾钩子：一件新证据，或一个新威胁。

**揭示顺序（不可调换）**：新郎是替身 → 无名尸就是沈峥 → 周启年收钱改结论 → 宋婉仪造了替身，但不是凶手 → 宋知远是凶手 → 林晚当庭认错，改写报告。

---

## 二、底牌（编剧掌握，观众逐步知道）

- **游艇夜**：沈峥查到舅舅借海外港口洗钱，当面摊牌。宋知远用扳手砸他后脑，推下海。沈峥落水前扯下宋知远一枚船锚袖扣，攥在手里。沈砚醉倒在船舱，只记得“有人换了衬衫”。
- **无名尸**：几天后尸体冲上岸，面部损毁。林晚解剖，初稿写明三点：后脑凹陷骨折（钝器）、左手虎口旧疤、掌心船锚形压痕，袖扣登记为物证。周启年删掉这三处，改成“意外”，逼她签字，三天内火化，袖扣交回宋知远。宋知远后来照原样补打了一枚，新的比旧的亮。
- **虎口疤**：沈峥小时候替沈砚挡碎玻璃留下的。程野没有。
- **那块表**：订婚时沈峥把自己的旧表给了林晚，上游艇前说“回来给你换块新的”。“沈峥”回来后从没问起这块表。
- **两年没认出**：假沈峥回国就称养病，避而不见。一年前当众退婚，是宋家怕她迟早看穿。
- **宋婉仪**：只知道儿子落水，尸体没找到，为保住遗嘱里的股份，让弟弟找人顶替。她不知道儿子被杀，更不知道儿子在林晚的解剖台上躺过、又被当无名尸烧了。
- **程野的软肋**：妹妹程小满在医院长期住院，费用由宋知远出，也被宋知远捏在手里。

## 三、五段结构

### 第一段 婚礼撕替身（1–10 集）
- **目标**：让所有人看见“新郎不是沈峥”。
- **证据**：交换戒指时摘下白手套，虎口光洁（第 1 集钩子：她想起解剖台上那道疤）→ 订婚照与婚礼照对比 → 签名笔迹的停顿 → 眼镜：沈峥高度近视，新郎戴的是平光镜。
- **反扑**：宋婉仪说她“被退婚气疯了”；沈砚嘲讽；苏曼丽踩她“摸死人晦气”；周启年以“精神不稳定”停她的职。
- **爽点**：每次被泼脏水，她都当众用一样证据顶回去，沈家一次比一次难堪。
- **转折**：第 8 集答谢宴，苏曼丽假装推搡，往她口袋里塞了一张房卡，房间里留着程野的旧护照，上面是另一个名字。
- **段尾钩子（10）**：周启年打来电话：“三年前那份报告，签字的是你。”

### 第二段 无名尸是谁（11–22 集）
- **目标**：证明三年前那具无名尸就是沈峥。
- **证据**：她私留的组织蜡块 → 重切的病理切片 → 沈砚的头发做 DNA 比对 → 原始尸检照片上的虎口疤。
- **反扑**：档案室“失火”，蜡块被调包；沈家买热搜说她借死人炒作。
- **人物**：沈砚从不信到动摇。第 16 集 DNA 结果出来，他亲眼看到，成了内应。林晚找到程小满，第一次明白程野也是人质。
- **爽点**：她当场验出调包蜡块年份不对，周启年在全中心面前下不来台。
- **段尾钩子（22）**：周启年把她签了字的“意外”报告甩给媒体：“当年签意外的是她，如今喊他杀的也是她，造假的就是她。”宋婉仪同时得知，儿子是被当无名尸烧掉的。

### 第三段 签字的人（23–36 集）
- **目标**：扳倒周启年，拿到“谁出的钱”。
- **证据**：周启年的金表，价格和送表人都查得到 → 三年前那笔转账的流水 → 周启年为留后手私录的一段录音。
- **反扑**：林晚被立案调查“出具虚假鉴定”；第 30 集苏曼丽为苏家港口生意反水，改口说房卡是林晚偷的、护照是伪造的。
- **人物**：林晚对着镜头承认“那份报告是我签的”，被围攻也不改口。沈砚想起游艇夜的碎片。
- **爽点**：周启年在自己办公室被金表和流水当面拆穿。
- **段尾钩子（36）**：录音只录到一句“宋先生放心”。所有人都看向宋婉仪。

### 第四段 主母与舅舅（37–50 集）
- **目标**：排除宋婉仪，锁定宋知远。
- **误导**：37–42 集证据似乎都指向宋婉仪，宋知远一边“护姐姐”，一边推她顶罪。
- **证据**：宋婉仪承认造替身，拿出“落水”当晚的通话记录，证明她当时不在船上 → 原始尸检照片上掌心的船锚压痕 → 宋知远腕上那对袖扣，一新一旧。
- **反扑**：第 45 集宋知远给程野安排“意外”（车祸或落水），林晚和沈砚抢回人。
- **人物**：程野反水，交出整容合同和宋知远的指令，林晚把程小满转出宋知远的控制。苏曼丽给出港口货单，算是还上答谢宴那份情（不算第二次反水）。
- **爽点**：家宴上林晚把三年前的尸检照片和袖扣并排放在宋知远面前，满桌沈家人当场变脸。
- **段尾钩子（50）**：宋婉仪知道是弟弟杀了儿子，站到林晚这边；宋知远连夜登船准备出海。

### 第五段 庭审与改写（51–60 集）
- **51–54**：码头游艇截人。宋知远想用当年那份“意外”报告和林晚的签名脱罪：“你们自己的法医签的。”
- **55–58 庭审**：林晚以证人身份出庭，先当庭承认当年违心签字，再逐一给证据：颅骨骨折形态与扳手吻合、虎口疤、DNA、袖扣、程野证词、录音。宋知远认罪。
- **59**：判决。宋婉仪交出沈氏；程野带妹妹去自首；周启年同案判刑。
- **60**：林晚重新写下“死者沈峥，他杀”，签上自己的名字。最后一场在墓园，她摘下那块表，放在沈峥的墓前。

## 四、人物弧线与退场

| 人物 | 弧线 | 退场 |
|---|---|---|
| 林晚 | 冷着脸赢每一局 → 被自己的签名反噬 → 主动认错 | 改写报告，表放在墓前 |
| 程野 | 怕死的替身 → 自己也被安排“意外” → 为妹妹转身作证 | 带妹妹自首 |
| 沈砚 | 嘲讽她 → DNA 后成内应 → 补全游艇夜的记忆 | 出庭作证，接手沈峥那份未竟的事 |
| 苏曼丽 | 踩人 → 塞房卡求救 → 为生意反水 → 交货单 | 离婚，带苏家退出港口合作 |
| 周启年 | 压人的领导 → 金表、流水被拆穿 | 第 36 集倒台，第 59 集判刑 |
| 宋婉仪 | 轻声细语地护股份 → 被当靶子 → 知道真相 | 交出沈氏 |
| 宋知远 | 最可靠的舅舅 → 借刀杀人 → 想出逃 | 认罪伏法 |

**败因**：周启年贪钱又怕死，所以留了录音；宋知远太自信，补打一枚袖扣继续戴。两人不是蠢，是被自己的习惯出卖。

## 五、写分集时的硬规则

- 每集只推进一件证据，不得一集交两张底牌；上面的揭示顺序不得调换。
- 证据必须靠林晚的专业拿下；别人可递线索（如房卡），读懂的必须是她。
- 林晚不抬声调、不哭喊、不求人；她的爽点是平静地念出结论。
- 沈峥只在闪回出现，靠虎口疤和那块表认人，不加新设定。
- 不新增凶手、帮凶或新的身世反转；感情线停在战友，墓前那场只属于沈峥。

## 六、AI 拍摄约束

- **固定场景**（10 个，新增须先改本骨架）：婚礼宴会厅、酒店房间、解剖室、档案室、主任办公室、沈宅客厅、医院病房、游艇甲板（闪回及 51–54 集）、法庭、墓园。
- **造型锁死**：外形照选题卡执行，全剧不换；林晚的风衣旧表、宋知远的袖扣，出场必入镜。
- **同脸区分**：程野与沈峥同脸。程野戴白手套或露出无疤虎口；沈峥的闪回用冷蓝调色，虎口疤给特写。
- **每集不超过 3 场戏**；证据要有干净的特写，便于生成和复用。
