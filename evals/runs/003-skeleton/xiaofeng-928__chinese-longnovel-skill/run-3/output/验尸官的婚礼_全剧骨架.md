# 《验尸官的婚礼》全剧骨架

60集竖屏｜每集1–2分钟｜AI拍摄｜分集大纲和剧本与本骨架冲突时，以骨架为准。

## 一、主线与铁律

- 明线：证明新郎是替身 → 证明无名男尸就是沈峥 → 找出谁杀了沈峥。
- 暗线：林晚每离真相近一步，就离她自己签的假报告近一步。要给凶手定罪，她得先推翻自己的签名。
- 单集循环（每集必有）：①一件看得见、能拍特写的证据；②沈家或周启年毁证、抹黑；③林晚用专业拆招，拿到更硬的下一件；④集尾停在一个新物件或一句话上。
- 林晚只靠证据赢，不靠巧合，也不靠别人救。她从不抬声调，赢的时候也一样。
- 大打脸节点：苏曼丽与宾客（1–5）→ 程野（13）→ 周启年（44）→ 宋婉仪（50）→ 宋知远（58）。

## 二、四幕结构

### 第一幕 婚礼（1–10）：认出替身

- 1：林晚以"晦气前任"的身份出席婚礼，被苏曼丽当众羞辱。交换戒指时新郎的白手套滑落，左手虎口光洁。闪回解剖台：无名男尸同一位置有疤。集尾台词："真新郎，三年前就躺在我的解剖台上。"
- 2–3：她当场指认，被宋婉仪轻声细语地"体面"请出场，热搜写成"女法医大闹前任婚礼"。她回档案室调尸检照片，照片已经被抽走。
- 4–5：答谢宴上苏曼丽当众泼她酒，私下塞给她房卡。在房间里，苏曼丽说出新婚夜的疑点，交出丈夫用过的剃须刀片。
- 6–8：程野先收买、后威胁；周启年约谈她："那份报告上，签的是你的名字。"沈砚当众讥讽她想攀回沈家。
- 9–10（付费卡点）：刀片和婚宴上沈砚用过的酒杯做比对，DNA结果显示新郎和沈砚不是亲兄弟，样本随即被调包。林晚打开私人储物柜：三年前被逼签字那天，她偷偷留下了一套病理切片和自己的手写初稿。

### 第二幕 撕开沈家（11–30）：拉内应，逼替身，认死者

- 11–14：林晚说出那道疤的来历（沈峥小时候替沈砚挡过碎玻璃）。沈砚试探："哥，你的疤呢？"程野答错。沈砚成为内应。
- 15–19：沈家反扑。宋婉仪联手周启年，以"泄露尸检资料"为由让林晚停职。宋知远以和气舅舅的身份主动示好，暗中把线索引向宋婉仪。本段证据：签名笔迹、整容医院缴费单（付款方是宋家海外公司）。
- 20–25：雨夜，林晚单独逼问程野。程野承认自己是替身，但不知道沈峥是怎么死的，只怕自己哪天也会"意外"。程念登场：程野的妹妹，宋家拿捏程野的筹码。程野的认罪录音被沈家抢走砸毁，程野翻供。
- 26–30（中点）：切片与沈砚做亲缘比对，无名男尸就是沈峥。林晚把另一半切片正式送去司法鉴定。周启年立刻放出她当年签的"意外"结论，舆论翻转，说她才是帮凶。集尾她重读手写初稿："死者右手掌心，有锚形压痕。"

### 第三幕 代价（31–45）：她的签名成了武器

- 31–34：宋知远继续把矛头引向宋婉仪。林晚当面对质，宋婉仪承认找人顶替，但坚称儿子是落水意外。沈砚崩溃坦白：那晚他也在游艇上，喝醉了，什么都不记得。
- 35–40（低谷）：宋知远拿港口合同要挟苏家。苏曼丽反水，偷走林晚手里的切片烧掉，还作证说林晚勒索沈家。林晚被立案调查。周启年逼她签字承认伪造DNA，否则就追究三年前那份假报告。
- 41–45：林晚选择自首，交出三年前偷录的周启年逼签录音。这段录音能定周启年的罪，也能定她自己的。周启年被带走，林晚被暂停执业。周启年那块金表查到了宋知远名下的购买记录，宋知远推说是"替姐姐打点"，嫌疑仍压在宋婉仪身上。

### 第四幕 船锚（46–60）：锁定凶手

- 46–49：程野发现宋知远用程念的名字开了洗钱账户，明白自己"没用"的那天快到了，于是倒向林晚。司法鉴定结果回来。
- 50：沈峥三十岁股权交割大会。程野当众摘下手套，林晚出示签名、虎口和司法鉴定结果，宋婉仪在股东和二房面前被揭穿。宋知远起身"大义灭亲"，指控自己的姐姐。
- 51–55：宋知远给程野制造"意外"，林晚凭现场痕迹识破，把人救下。沈砚修复了那晚的旧手机，录音里有沈峥和宋知远争吵港口账目的声音，接着是一声闷响。宋知远的袖扣少过一枚，补配的那枚有细微差异，和掌心压痕对上；游艇工具箱里少了一把扳手。苏曼丽再次反转，交出港口账本。宋婉仪得知凶手是弟弟，交出遗嘱原件和账目。
- 56–58：宋知远从港口出逃，在夜里的集装箱区被捕，面对证据认罪。
- 59：庭审。林晚以原鉴定人身份出庭，当庭推翻自己三年前的报告，重新写下"死者沈峥，他杀"，签上自己的名字。
- 60：宋婉仪交出沈氏；程野带着程念自首；墓园里，林晚把表放在沈峥墓前。

## 三、证据链（按出场顺序，不得提前）

虎口疤（1）→ 被抽走的尸检照片（3）→ 剃须刀片DNA（5–10）→ 私藏切片与手写初稿（10）→ 签名笔迹（17）→ 整容缴费单（19）→ 程野认罪录音（24）→ 切片DNA证实死者是沈峥（28）→ 初稿里的锚形压痕（30）→ 逼签录音（43）→ 金表购买记录（45）→ 司法鉴定（49）→ 旧手机录音（53）→ 补配袖扣、缺失的扳手（54）→ 港口账本（55）。

证据被毁之前，必须先让观众看清它的样子。

## 四、信息揭示锁

- 宋知远是凶手：第53集前只埋暗线（袖扣特写、他的手、他主动帮忙），不点破。
- 沈砚当晚在游艇上：第33集前不提。
- 逼签录音：第42集前不提，可以拍林晚摸储物柜、听耳机时的反应。
- 宋婉仪到第54集才知道儿子是被杀的。
- 程念第20集前不出场，第8集可以拍程野手机里一个女孩的照片。

## 五、人物推进

- 林晚：用证据赢别人 → 证据指向自己 → 亲手推翻自己的签名。那块表是沈峥订婚时送的，第60集离开她的手腕。
- 沈砚：敌视 → 内应（13）→ 自责（33）→ 交出关键录音（53）。
- 苏曼丽：踩人 → 求救（4）→ 反水（37）→ 回头（55）。
- 程野：收买、威胁 → 私下认罪 → 翻供 → 倒戈（49）→ 自首。
- 宋婉仪：体面的加害者 → 被揭穿 → 知道真相后崩溃 → 放手。
- 周启年：权威 → 要挟 → 落网（44）。
- 宋知远：最可靠的舅舅 → 暗中操盘 → 认罪（58）。

## 六、AI拍摄约束

- 外形锚点每集不变：林晚齐耳短发、灰风衣、男式旧表；程野金丝眼镜、白手套；沈砚寸头、黑耳钉、西装不扣；苏曼丽长卷发、酒红指甲；周启年金表、胸前挂老花镜；宋婉仪旗袍、珍珠耳环；宋知远船锚袖扣。
- 主场景控制在9个：婚宴厅、酒店房间、解剖室、档案室与储物柜、沈家老宅、游艇、港口、法庭、墓园。
- 游艇那晚只用闪回碎片（暗光、局部特写、声音），不拍完整的打斗和落水。
- 证据一律用特写插入镜头。单场主要角色不超过4人，群戏背景虚化。
- 每集开头3秒接上集钩子，结尾停在物件或台词上。
