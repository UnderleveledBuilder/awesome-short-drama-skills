# 《验尸官的婚礼》全剧骨架

60集 × 1–2分钟｜竖屏｜AI拍摄｜女频·大女主·复仇·悬疑·豪门

## 一、总纲

**主线问题**：三年前是谁杀了沈峥？

**双刃引擎**：林晚每证明一次"沈峥是被杀的"，就多证明一次"我签过假报告"。外面要赢，她自己就得认错。到结局她亲手推翻自己的签名，两条线在这里合上。

**单集铁律**（写分集大纲时逐集对照）：
1. 每集一件看得见、能拍特写的证据（物、图、声），不重复。
2. 每件证据都要挨一次反击：毁、偷、调包、抹黑、威胁，至少一种。
3. 结尾钩子五类轮换：证据将揭／证据被毁／身份将露／新敌入场／有人倒戈，相邻两集不用同一类。
4. 打脸只落在沈家、周启年、宋知远身上。林晚不靠男人、不靠运气，只靠专业。

## 二、设定补充（选题卡没写，骨架定下，后面不改）

- 沈峥左手虎口有一道旧疤。无名男尸在海里泡了九天，脸认不出，但虎口有同样的疤。当时沈家说沈峥在国外养病，每周都有"他"的消息，林晚把这个疑点压下去了。这是她第二根刺。
- 旧表是沈峥出事前一周送她的订婚表，程野不知道有这块表。
- 林晚三年前私留了一块组织蜡块（就是"切片"），藏在法医中心的废旧标本柜，全剧最重的物证。
- 沈峥"落水"后对外说出国养病，半年后程野顶着他的身份回国。一年前退婚，是程野怕前未婚妻离近了认出他。
- 程野的妹妹程小禾，19岁，是宋知远拿捏程野的筹码。
- 凶器是游艇工具箱里的扳手。三年前的游艇维修单上写着工具箱"整套更换"。

## 四、五段结构

### 第一段 婚礼局（1–10）：她看见了
任务：3集内立住"替身＋解剖台"，第10集打第一个付费卡点。
- 1集：林晚被嘲"晦气前任"，新郎白手套滑落，虎口光洁。结尾：她翻出旧尸检照片，那道疤。
- 2–4集：当场试探，问表的来历，他答错。沈家叫保安，苏曼丽泼酒，媒体拍她"闹婚礼"。小打脸：她当众点出新郎签名笔顺不对。
- 5–8集：周启年以"影响单位声誉"停她的岗；宋婉仪派人删照片；她调原卷，发现原始结论页被换。宋知远出场，温和劝她"放下"，船锚袖扣特写（伏笔一）。
- 9集：答谢宴，苏曼丽把房卡塞进她手里。
- 10集【卡点】：房里是一张赌债借条，署名"程野"。门外有人把门反锁。

### 第二段 揭替身（11–25）：证明他不是沈峥
任务：一集一件身份证据，沈家一件件毁，林晚一件件补。
- 证据阶梯：借条 → 整容医院病历 → 牙科记录 → 沈峥旧护照指纹 → 程野模仿训练录像。
- 沈家反击：烧病历、买通牙医、网暴"女法医纠缠前任"、周启年把她调去守停尸房。
- 12集：她从标本柜取出蜡块。观众知道，沈家还不知道。
- 18集：沈砚看到两张手部对比照，倒戈。
- 22集：宋知远替她"摆平"网暴，她把蜡块的事告诉了他，袖扣入镜（伏笔二）。
- 25集【中高潮】：沈砚头发和新郎DNA比对，不是同胞。宋婉仪私下认了替身，咬定"我儿子是落水，意外"。结尾林晚问："哪天落的水？"日期和无名男尸入库那天一样。

### 第三段 中点翻转（26–35）：从"他是谁"到"谁杀了他"
- 26–29集：沈家知道有蜡块，三次来抢（调包、纵火、收买实习生），她都守住，一次比一次付出得多。
- 30集【中点】：蜡块DNA和沈砚是同胞。解剖台上那具无名男尸就是沈峥。林晚第一次失态：那份"意外"是她签的。
- 31–33集：她找回系统修改日志，"他杀"是被周启年的账号改掉的。伏笔三：她想起宋知远是唯一知道蜡块藏在哪的外人。
- 34集：她把证据交给警方，准备立案。
- 35集【反转】：她当年签字的报告被匿名发上网，"女法医伪造尸检包庇豪门"，她被停职调查。

### 第四段 低谷与反咬（36–48）
- 37集：程野出"意外"车祸，林晚从伤痕看出是人为，救下他。他动摇了，可妹妹在宋知远手里，他不敢开口。
- 39集：苏曼丽反水，拿林晚的证据复印件跟沈家换港口合同。
- 40–42集：宋知远把嫌疑引到沈砚身上："那晚游艇上就他喝醉了。"沈砚被带走。
- 43集：林晚做颅骨伤口复原，证明凶器是扳手，凶手185以上、右手发力，跟沈砚对不上。
- 44集【大反转】：沈砚想起那晚的一点银光，是船锚袖扣。观众和林晚同时确认凶手是宋知远。
- 45–48集：转打周启年：金表来历、海外账户、三天火化的审批单。48集周启年落马，认了受贿，又把林晚拖下水："字是她签的。"

### 第五段 终局（49–60）
- 49–51集：宋知远反扑，转移资产、绑走程小禾、威胁程野。林晚和沈砚找到游艇维修单。
- 52集：林晚把颅骨复原图放到宋婉仪面前。母亲这才知道，儿子是被弟弟砸死的。
- 53–54集：宋婉仪配合设局救回程小禾；程野交出三年来偷录的宋知远威胁录音。
- 55集：苏曼丽带港口账本出庭。
- 56集：程野带妹妹自首。
- 57–58集【终极高潮】：法庭上，林晚申请重新出具鉴定，当庭承认三年前签了假报告，写下"死者沈峥，他杀"，签名。
- 59集：宋知远认罪伏法，宋婉仪交出沈氏。
- 60集：墓园，林晚摘下那块表，放在沈峥墓前。

## 五、压力梯度

| 集数 | 主压力 | 手段 | 林晚失去 |
|---|---|---|---|
| 1–25 | 宋婉仪／沈家 | 钱、保安、舆论 | 名声 |
| 26–48 | 周启年 | 停职、调岗、她的签名 | 工作、清白 |
| 44–60 | 宋知远 | 车祸、绑架、灭口 | 身边人的安全 |

对手每升一级，林晚丢的东西也要跟着升一级，不许回落。

## 六、AI拍摄约束

- **场景库**（不加新场景）：婚宴厅、酒店房间、解剖室／标本库、周启年办公室、沈家客厅、游艇（只拍夜间闪回，不拍落水全景）、医院、法庭、墓园。
- **识别锚点**，人物出镜必带：林晚灰风衣＋旧表；程野金丝眼镜＋白手套（揭穿后摘掉）；沈砚黑耳钉；苏曼丽酒红指甲；周启年金表；宋婉仪珍珠耳环；宋知远船锚袖扣。
- 每集不超过2个场景、4个有台词的角色；证据必给特写；不拍打斗、水下、追逐；尸体只出照片和局部。
- 林晚不抬声调，一句话打脸，不说长篇。
