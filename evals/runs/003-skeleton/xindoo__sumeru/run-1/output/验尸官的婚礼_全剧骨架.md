# 《验尸官的婚礼》全剧骨架

60 集竖屏，每集 1–2 分钟，AI 拍摄。分集大纲和剧本都不能违背本骨架。

## 一、发动机

**主题**：她要推翻真凶，最后要推翻的是自己签过的字。

**双线**
- 明线：谁杀了沈峥。嫌疑逐层上推：程野 → 宋婉仪 → 周启年 → 宋知远。
- 暗线：林晚三年前签的“意外”报告。每近真相一步，她自己的责任就多曝光一层。

**每集铁律**
1. 林晚每集亮出一样**看得见**的证据，不靠嘴推理赢；阶梯外的集用小证据补位。
2. 关键证据出现后 1–2 集内必有反扑：毁证、调包、抹黑或威胁。
3. 每集结尾一个钩子：新证据、证据被毁、反水、身份松动。
4. 打脸只落在沈家（宋婉仪、程野，前期加苏曼丽）和周启年，终局落在宋知远。

## 二、时间线（锁死，分集不得改）

- **四年前**：林晚与沈峥订婚。
- **三年前·出事前一周**：沈峥把戴了多年的旧机械表扣到她腕上：“先替我戴着。”
- **三年前·游艇夜**：沈峥约舅舅宋知远摊牌港口洗钱的事。宋知远用扳手砸他后脑，推他下海。沈峥倒下前扯掉了宋知远一枚船锚袖扣。沈砚同船，醉后只剩碎片。
- **三天后**：一具面部被礁石毁坏、没有证件的男尸送进市法医中心。林晚主检，查出后脑凹陷性骨折，结论“他杀”。她记下左手虎口有旧疤，却没往沈峥身上想，沈家对外只说沈峥“急病出国治疗”。打捞照拍到死者手里攥着一枚袖扣，物证袋却先被周启年截下，没到她手上。
- **改报告**：周启年收了宋知远的钱，把结论改成“意外坠海”，逼林晚签字，三天内火化。原始照片和袖扣被他私藏，做成要挟宋知远的保命包。病理切片按规定存档，他没在意，这是全剧命门。
- **顶替**：宋知远告诉姐姐，沈峥是醉酒落水、尸骨无存，劝她找替身保住股份；他自己则借傀儡握住沈氏一半股份，继续洗钱。程野整容几个月后“回国”，常年戴手套，以“病后性情大变”为由疏远林晚，一年前当众退婚。
- **现在**：股权交接要“沈峥”本人签字，又要联姻锁住苏家港口生意，于是有了婚礼。苏曼丽发请柬给林晚，为的是羞辱她。

## 三、四幕结构

### 第一幕 · 婚礼（1–10 集）：认出替身
- **1 集**：婚礼受辱。交换戒指时新郎摘下白手套，虎口光洁，闪回解剖台上那道疤。林晚：“新郎不是沈峥。”
- **2–5 集**：她被当成疯前任，苏曼丽带头踩，宋婉仪轻声请她出去。林晚拿旧订婚照上的疤对比婚礼直播截图。沈家拿出“激光祛疤”病历反扑；她用微距照片证明那只手从未治疗过，首次打脸沈家。
- **6–8 集**：周启年以“精神状态不稳”停她的职。她调档发现，当年男尸照片已被换掉。
- **9–10 集（付费卡点）**：答谢宴上苏曼丽偷塞房卡，说“他夜里叫另一个名字”，交出替身掉落的旧证件照，是张陌生的脸。钩子：那具男尸的切片还在库里。

### 第二幕 · 替身（11–30 集）：证明三年前躺在解剖台上的是沈峥
- **11–15 集**：婚宴香槟杯上的指纹，和沈峥留在她家旧物上的不符。反扑：她家被入室，旧物被烧；网上流出“法医跟踪前任”的剪辑视频。
- **16–20 集**：沈砚来警告她收手，看完比对后动摇，第 20 集抽血做 DNA。
- **21–24 集**：周启年下令销毁切片，林晚只抢出一张玻片。顺着证件照，她查到程野：模仿演员，欠着赌债，妹妹的疗养院费用一直由匿名账户支付。
- **25 集**：DNA 显示玻片主人与沈砚是同胞兄弟。“三年前躺在我台上的，是沈峥。”字幕定格在她当年的签名上。
- **26–29 集**：程野想跑，险些“意外”身亡，林晚救下他和妹妹，他松口。
- **30 集（中点大爽点）**：股东大会签字现场，林晚当众甩出 DNA 报告，程野摘手套认了。宋婉仪颜面扫地，当场反咬：“那份‘意外’报告，签字的就是你。”

### 第三幕 · 签名（31–45 集）：林晚自己成了被告
- **31–35 集**：林晚被立案调查，遭全网骂“收钱造假”。宋婉仪认下替身，咬定儿子死于意外。宋知远以“可靠的舅舅”身份替她请律师，每次出场镜头都扫过袖扣。
- **36–40 集**：林晚追查周启年那块和工资不相称的金表，购买记录指向一家海外空壳公司（第 45 集才对上宋知远）。40 集全员会上，周启年甩锅：“字是林晚签的。”林晚回他：“我签了，我认。你收的钱，你也得认。”周启年被当场带走。
- **41–43 集**：周启年想用保命包换减刑。宋知远以港口生意逼苏家，苏曼丽**唯一一次反水**，把保命包的位置泄露出去，原件被毁。宋知远伪造视频，嫁祸醉酒的沈砚推兄下海。林晚落入谷底。
- **44–45 集**：旧表在推搡中三年来第一次停了。修表师傅打开后盖，里面藏着一张存储卡。钩子：沈峥的声音传出来，“晚晚，如果你听到这个，是舅舅。”

### 第四幕 · 他杀（46–60 集）：真凶与她自己的报告
- **46–49 集**：宋知远撕下面具，抢卡，拿程野妹妹做人质。林晚设局保卡，程野指认是宋知远雇了他。
- **50 集（情感顶点）**：宋婉仪听完儿子最后的录音，崩溃，转身倒戈。
- **51–54 集**：苏曼丽回头，交出她私下翻拍的保命包：颅骨原始照，以及死者手攥船锚袖扣的打捞照。林晚由打击角度推算凶手身高 185 以上、右手持械，洗清沈砚；又对出宋知远那对袖扣有一枚是新配的。
- **55–58 集**：庭审。辩方攻击她：“证人自己签过意外报告。”林晚当庭推翻自己三年前的结论，主动请求接受调查，重新写下“死者沈峥，他杀”，签上自己的名字。录音、照片、程野和宋婉仪的证词压上，宋知远认罪。
- **59–60 集**：宋婉仪交出沈氏，程野带着妹妹去自首。墓园，林晚把表放在沈峥墓前，表针重新走动。

## 六、红线

- 沈峥只出现在照片、闪回和录音里，与程野同脸，靠虎口疤区分。
- 宋婉仪第 50 集前不知道儿子是被杀的。宋知远第 44 集前不被林晚明面怀疑，但袖扣反复入镜。
- 苏曼丽只反水一次。林晚不靠巧合或直觉赢。

## 七、AI 拍摄约束

- **固定场景（8 个）**：婚宴厅、解剖室、法医中心办公室、沈家老宅、酒店房间、游艇（仅闪回）、法庭、墓园。
- **造型锁定**：林晚灰风衣＋旧表，程野白手套＋金丝眼镜，沈砚黑耳钉＋敞怀西装，苏曼丽酒红指甲，周启年金表＋老花镜，宋婉仪旗袍＋珍珠，宋知远船锚袖扣。
- **少打斗**：靠证据特写和对峙台词。
