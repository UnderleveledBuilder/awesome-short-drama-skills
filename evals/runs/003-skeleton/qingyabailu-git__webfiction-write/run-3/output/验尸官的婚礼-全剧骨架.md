# 《验尸官的婚礼》全剧骨架

60 集｜竖屏｜每集 1–2 分钟｜AI 拍摄
本骨架管后续所有分集大纲和剧本，冲突时以本文为准。

## 一、核心

- **主线问题**：三年前是谁杀了沈峥？
- **暗线问题**：林晚敢不敢推翻自己签过的那份报告？
- **引擎**：每集一件看得见的证据 → 沈家毁证或抹黑 → 林晚反杀，离凶手近一步，也离自己的签名近一步。
- **终点**：法庭上，她把"意外"改回"他杀"，签上自己的名字。

## 二、底层时间线（全剧只认这一版）

- **四年前**：林晚与沈峥订婚。沈峥左手虎口有一道旧疤。
- **三年前**：沈峥查到舅舅宋知远借沈氏海外港口洗钱。出事前一天，他把自己的旧表交给林晚"帮我拿去修"。当晚游艇上，宋知远用扳手砸他后脑，推下海；沈砚醉倒在船舱。宋知远告诉姐姐是"醉酒落水"，宋婉仪为保股份对外称儿子出国养病，找程野整容顶替。
- **同月**：海边捞起一具泡水十余天、面目全非的无名男尸，林晚主检，写"他杀"（后脑凹陷骨折，形状像扳手）。周启年从死者右手取走一枚船锚银袖扣，没登记进证物清单；又逼林晚改成"意外溺水"，三天内火化。林晚签了字，私下留了一块组织蜡块。那段时间"沈峥"每周从国外发语音报平安，她没往那上面想。
- **一年前**："沈峥"回国，当众退婚。替身最怕的就是最熟悉他的人。
- **现在**：婚礼。距沈峥三十岁生日、股权交接还剩一个月，这是全剧的倒计时。

## 三、人物功能与弧线

- **林晚**：只认证据，不哭不喊。她唯一的污点是那份签字，私藏蜡块是唯一一次越线，两件都要在结局付代价。
- **程野**：白手套 → 动摇 → 当众摘手套。软肋是透析的妹妹，医药费由宋婉仪出。
- **沈砚**：敌意 → 试探 → 内应（第 16 集）→ 说出游艇那晚（第 45 集）。
- **苏曼丽**：踩林晚 → 塞房卡求救 → 结盟 → 为港口生意反水（第 42 集）→ 被宋知远甩掉后交出港口记录。
- **宋婉仪**：前半程的明面对手，负责抹黑和顶替。第 38 集坦白顶替，咬定是意外；第 50 集知道真相后崩溃，倒戈。
- **周启年**：第一个被打脸的人。停职林晚、毁档案；被宋知远灭口未遂，最后出庭作证。
- **宋知远**：第 40 集前一直是"最可靠的舅舅"，暗中给林晚递线索，把怀疑引向宋婉仪。第 40 集前不许给他坏人镜头。

## 四、五段结构

**第一段　婚礼识破（1–10）**
1：交换戒指，新郎摘手套，虎口光洁。林晚当场说"你不是沈峥"，被拖出去，满堂哄笑。卡点：闪回解剖台上那只手，虎口有疤。
2–5：宋婉仪发通稿"前未婚妻精神失常闹婚"，周启年把她停职；中心原始记录被换，只剩她签字的"意外"版。
6–9：沈砚警告她别碰沈家。宋知远第一次出场，替她说话（袖扣一只新、一只旧）。答谢宴上苏曼丽当众泼酒，趁乱塞房卡。
10【付费点】：房间里，苏曼丽递来新郎的头发："他不是我丈夫，救我。"林晚回家，藏蜡块的冰箱被撬空。

**第二段　替身攻防（11–25）**
11–13：被偷的是假蜡块，真的在她大学导师那儿。宋知远安慰她时说出了"蜡块"两个字，可没人告诉过他（线索）。沈家让程野割出一道新疤，林晚在家宴上逼他摘手套，当众验出疤龄不到一个月。
14–16：新郎头发和沈砚血样比对，没有亲缘；沈砚弄来的替身指纹，和沈峥旧驾照档案也对不上。沈砚成为内应。
17–21：整容医院记录挖出程野的真名、赌债和妹妹，程野第一次动摇。观众看到妹妹的透析缴费单，付款人是宋婉仪。
22–25：蜡块与沈砚血样做亲缘比对，结果是同胞兄弟。无名男尸就是沈峥。卡点：林晚看着报告上自己当年的签名。

**第三段　三年前的案子（26–40）**
26–29：周启年的金表，购买日期是火化后第五天；转账走的是海外空壳公司。
30【付费点】：林晚在沈氏发布会上公开 DNA 报告。周启年抛出她亲笔签的"意外"报告，反咬她"早知是沈峥，故意隐瞒"。她被立案调查，跌到谷底。
31–35：程野偷录宋婉仪的话："到死你都是沈峥。"林晚在家族董事会上放出录音。
36–39：宋婉仪承认顶替，咬定儿子是落水；周启年想开口，坠楼重伤，在 ICU 里用手指写给林晚一串保险柜密码。
40【付费点】：林晚从周启年办公室的保险柜取出"保命袋"，里面是那枚船锚袖扣。她抬头，宋知远正替她拉开车门。

**第四段　舅舅（41–52）**
41–44：宋知远开出港口独家合约，苏曼丽反水，供出沈砚和袖扣下落。袖扣原物被毁，沈砚被逐出沈家；但林晚事先提取过袖扣缝里的血迹，检验报告还在。
45–48：沈砚说出游艇那晚的事。他醉酒时手机一直在录，文件损坏。林晚修复出一段录音：沈峥说"舅舅，账不在我身上"，一声闷响，宋知远说："把扳手扔了。"
49–50：林晚想起那句"账不在我身上"，第一次把表拿去修，后盖里藏着沈峥留的储存卡，是洗钱账目，动机补齐。宋婉仪看完，崩溃。
51–52：生日当天的股权交接仪式，程野当众摘下手套："我不是沈峥。"沈砚救出程野的妹妹；被宋知远甩掉的苏曼丽交出港口出入记录，宋知远在宴会厅门口被警方截住。

**第五段　签名（53–60）**
53–56：辩方猛攻：蜡块是私藏的，证据链不合法；法医本人的结论就是"意外"。要让证据成立，林晚只能当庭指认自己当年的报告是假的。
57–58：庭审。周启年醒来作证。林晚当庭推翻原报告，写下"死者沈峥，他杀"，签上名字，接受处分。
59：宋知远认罪伏法，宋婉仪交出沈氏，程野带着妹妹去自首。
60：墓园。林晚把表放在沈峥墓前，表针还在走。

## 六、写作与拍摄铁律

1. **每集三拍**：前 5 秒接上集卡点；中段一件证据落地，必须有物件特写；结尾留一个新威胁或新证据。
2. **证据要拍得出来**：疤、指纹卡、蜡块、报告签名、金表发票、录音波形、袖扣、储存卡。不许拿台词推理代替证据。
3. **反制分段升级**：第一段抹黑、停职；第二段偷证、伪造；第三段反咬、灭口；第四段策反、毁证；第五段攻击证据是否合法。同一种手段不连用两次。
4. **爽点靠证据当众落地**：打脸发生在婚宴、家宴、发布会、董事会、仪式、法庭这些有人围观的场合。
5. **视觉锚点每集固定**：林晚的深灰风衣和左腕旧表；程野的白手套和金丝眼镜（只有第 1、12 集被迫摘下片刻，第 51 集才主动摘）；沈砚没扣的西装和黑耳钉；苏曼丽的酒红指甲；宋婉仪的旗袍和珍珠；宋知远的船锚袖扣（第 40 集前一新一旧，第 41 集起换成一对新的）；周启年的金表。
6. **场景不超过九个**：酒店宴会厅、酒店房间、解剖室、法医中心办公室、沈家老宅、林晚公寓、医院、法庭、墓园。发布会和交接仪式用宴会厅，家宴和董事会用老宅。游艇只出现在闪回里，用夜景近景，不拍落水全景。
7. **闪回统一冷蓝调**：三年前的尸体不露脸，只拍手、后脑伤口、白布。
8. **禁区**：林晚不靠男人救场；沈峥不复活，也不搞双胞胎；宋知远第 40 集前不许有阴笑或独白。
