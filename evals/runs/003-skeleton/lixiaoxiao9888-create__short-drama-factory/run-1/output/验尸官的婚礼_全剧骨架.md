# 《验尸官的婚礼》全剧骨架

## 一、立项定盘
- 流派：混合。主线情绪流（契约贯穿），支线剧情流（"谁杀了沈峥"每单元揭一层）。
- 档位：标准档，60集，每集90~120秒，单集≤2场，AI实拍。
- 情绪契约：看林晚把证据一样样摆上桌，逼埋真相的人当众认账——最后她连自己的账也认。
- 双螺旋：每赢一次，外线离凶手近一步，内线离她签的假报告近一步。A她是"疯前任"，B她是"出假报告的人"，C她必须当庭认下自己的签名。
- 三件主证据分挂三单元：A一道疤，B一张切片，C一段录音。

## 二、每集发动机（管住所有分集）
亮一样看得见的证据 → 沈家毁证或抹黑 → 林晚用专业让证据"活过来"，对方当场付代价 → 真相进一步、自罪进一步。
硬规：每集必须有实物证据入画；反派每次作恶3集内必须吃到反击；集尾断在"结论出口前0.5秒"。

## 三、背景真相（只给编剧，不进台词）
三年前游艇上，沈峥查到舅舅宋知远借海外港口洗钱，被扳手砸后脑推下海；醉倒的沈砚被宋知远按了指纹在扳手上，留作后手。尸体半月后漂回成无名男尸，林晚初检"他杀"，记下虎口疤和掌心一道船锚形压痕。她打过电话，"沈峥"从国外接了——那是程野。周启年拿了宋知远的不正当利益输送，逼她改"意外"，三天火化。宋知远告诉姐姐是意外落水，宋婉仪为保股份找程野顶替。沈峥出事前把表留给林晚修，后盖夹层藏着一张存储卡，她戴了三年不知道。

## 四、四幕与付费墙
- 一幕1~12：婚礼当众说破，被拖出、停职、上热搜。
- 二幕13~34：沈砚倒戈，替身掉马，她从自证转为追查。
- 三幕35~49：宋知远反扑，内应被栽赃，同盟反水。
- 四幕50~60：底牌全开，庭审清算。
- 一级墙第10集：DNA记录注销人是周启年，断在她推开主任办公室门。
- 二级墙第22集：宋婉仪甩出报告"死因：意外，鉴定人：林晚"，断在全场看向她。
- 三级墙第42集：宋知远给她二选一：撤回翻案沈砚就出来，不撤沈砚替他坐牢。

## 五、单元链与回合表

### 单元A（1~22）执念：新郎是假的
对手：宋婉仪掌局，苏曼丽前台踩，程野被迫配合。闭环：亲缘鉴定当众坐实替身。
- 回合1（1~3）疤：交换戒指摘手套，虎口无疤；她翻出尸检照——尸体有同一道疤。沈家称激光祛疤，放"疯前任大闹婚礼"视频，周启年停她职。反将：祛疤必留皮纹断层，她当众验手，这块皮从没受过伤。
- 回合2（4~7）房卡：答谢宴苏曼丽塞来求救房卡，房里是新婚夜偷拍的"丈夫"耳后缝合线。宋婉仪收走手机，反告她擅闯新房。反将：她早拍下照片，按针距和愈合色差断出"两年内整容"。
- 回合3（8~10）酒杯DNA：她取新郎酒杯，比对三年前无名尸入库DNA。沈家报警说她非法采样，入库记录被注销。→一级墙。
- 回合4（11~14）程野本人：她挖出替身演员旧照和赌债。宋婉仪替他还债，拿他妹妹封口。第14集揭开请柬是沈砚匿名寄的。
- 回合5（15~18）牙片：沈砚不信她，拿哥哥旧牙片来试；牙片与尸检照片吻合。宋婉仪说牙片伪造，起诉她诽谤。她押上执业资格公开立誓。
- 回合6（19~22）兄弟鉴定：沈砚交出自己的血样；她依程序申请省级库调取备份。股东交割会上当众出结果：沈砚和新郎不是兄弟，和无名尸是。第21集程野掉马、交割冻结；第22集宋婉仪认"儿子落水意外"，反甩报告。
- 火种：她亲手签的"意外"，成了沈家最硬的盾。

### 单元B（23~40）执念：那具尸体是他杀（推翻自己）
对手：周启年，宋婉仪为保替身秘密护着他。打法：主动设局。闭环：周启年被专案组依法带走。
- 回合1（23~25）初检笔记：她交出三年前手写的"他杀"笔记。周启年说是事后补写，举报她出具虚假鉴定，她被立案调查。反将：笔记夹着当年的物证签收单，日期对上了。
- 回合2（26~28）切片：她违规私留的颅骨骨折处切片，有生前伤反应。周启年派人入室偷切片，再举报她私留检材。反将：偷走的是假的，真的在省级复核实验室。
- 回合3（29~31）火化记录：三天火化，签批人周启年；殡仪馆老工人作证。周逼工人改口。反将：登记本有周的亲笔签名。
- 回合4（32~34）假认罪：她当众认错，换周启年放松，引他销毁中心存档，沈砚埋点录像，拍下他亲手销毁存档。攻守转换。
- 回合5（35~37）金表：周启年腕上金表的付款方是沈氏海外贸易公司。宋婉仪第一次愣住——那是弟弟的线。
- 回合6（38~40）闭环：周启年被带走前说："钱不是你婆婆给的。"
- 火种：宋知远第一次在镜头里收起笑。

### 单元C（41~60）执念：谁杀了他，为什么
对手：宋知远。打法：用法医专业重建现场。闭环：庭审。
- 回合1（41~44）至暗：扳手照片上有沈砚指纹，沈砚被带走；苏曼丽为家里港口生意反水作伪证；程野失踪；她停职。→三级墙。第43集前15秒兑现：她选不撤，验出指纹是昏迷状态下被按上去的，纹线受力方向反了，沈砚取保。
- 回合2（45~47）船锚压痕：尸体掌心压痕对上宋知远的袖扣。宋说袖扣满街都是。反将：他那对袖扣一只新一只旧，补做发票就在出事后一周。
- 回合3（48~50）程野作证：沈砚救出程野妹妹，程野说出"学沈峥是从游艇那晚之后开始的"。苏曼丽带着港口货单回头。
- 回合4（51~54）母亲：她把切片和骨折形态摆给宋婉仪——"不是落水，是背后砸的"。宋婉仪倒戈。宋知远安排她"意外"（写意处理，未遂），沈砚记起那晚的片段。
- 回合5（55~57）录音：程野说"他三年一直在找一块表"。她打开后盖，存储卡里是沈峥生前录下的洗钱对话和威胁。
- 回合6（58~60）庭审：宋知远认罪伏法，宋婉仪交出沈氏，程野带妹妹自首。林晚当庭推翻自己的报告，写下"死者沈峥，他杀"，签名，并主动申报自己当年的责任。墓前放表。
