# 《验尸官的婚礼》全剧骨架

60集 × 1–2分钟｜竖屏｜AI制作｜分集大纲和剧本都得按这份骨架走，要偏离先改骨架

## 一、核

- **一句话**：被退婚的女法医在前未婚夫的婚礼上认出新郎是替身，她要一件件拿出证据，证明三年前自己解剖的无名男尸就是沈峥。最后一件证据，是她自己签的那份假报告。
- **核心戏剧动作**：林晚要给沈峥找回名字和死因 → 沈家为保股份毁证、抹黑，周启年拿她的签字要挟，宋知远在幕后栽赃。
- **倒计时**：按遗嘱，沈峥三十岁那天交接股份，就在婚礼后一个月（E30股东会）。替身必须撑到签字。
- **主题**（全剧不许说出口）：认证据，也得认自己的签名。

## 二、底层真相（编剧全知，观众分批知道）

1. 四年前，沈峥修林晚摔裂的旧机械表（他爷爷的），被表镜碎片割破左手虎口，留了疤。那块表从此戴在林晚手上。
2. 三年前，沈峥查到舅舅宋知远借港口洗钱。游艇上那晚沈砚醉倒在船舱，宋知远**左手**握扳手砸沈峥后脑，推他下海。沈峥挣扎时扯掉他一只船锚袖扣，掌心被硌出锚形压痕，袖扣卡进了甲板缝。
3. 宋知远用沈峥的手机给林晚发“出国养病”；跟姐姐说儿子是醉酒落水，劝她找替身保股份。
4. 七天后无名男尸上岸，面部损毁。林晚验出他杀，记下了虎口疤和掌心压痕，起过疑心，又被那条“养病”短信压了下去。周启年收钱改成意外，逼她签字，三天火化。病理蜡块按规定封存在档案室。
5. 程野整容顶替。一年前按宋家的意思当众退婚，因为身边有个法医太危险。妹妹程溪的病由宋知远出钱治。

## 三、林晚的弧光

- **Want**：证明新郎是假的，查出凶手。**Lie**：错在逼我签字的人，不在签字的我。**Need**：当众认下自己的签名。
- **外显锚点**：那块表和那份报告。弧光只靠她对这两样东西的动作来表现。
- **预算**：E1–15 不超过10%（一提报告就换话题）｜E30 伪变化：全场赢了，签字被翻出来时脱口一句“结论是周主任定的”，往回退｜E46 第一次摘下表锁进抽屉（至暗）｜E50 对周启年说“对，我签了”（85%）｜E58 当庭重签（100%）。

## 六、信息释放与伏笔

- **观众比林晚先知道**：E5宋婉仪知情；E20有幕后人；E40凶手是宋知远。E40–E53，宋知远每次靠近林晚都要让观众捏把汗。
- **全城知道**：E30替身曝光；E56宋知远是凶手。
- **伏笔**：表（E1→E60）｜船锚袖扣，E1宋知远扶起被推倒的林晚，特写一亮一暗（→E34→E54）｜宋知远左手倒茶（E3→E44→E54）｜港口汽笛（E12→E20→E56）｜白手套（E1→E59）｜E1林晚在签到簿签名，镜头扫过（→E58同一个签名）

## 七、单集铁律（AI竖屏）

1. **前3秒**：一个画面钩子（证据特写、一个动作或一句狠话），不回顾上集。
2. **每集一件看得见的证据**，给满屏特写插入镜头；证据道具全剧统一造型。
3. **单集节拍**：钩子 → 亮证据 → 对手反制 → 回手 → 集末钩子（最后5秒）。不超过3场戏，不超过4个说话角色，每集林晚至少回手一次。
4. **大爽点**必须当着被打脸的人。
5. **场景库锁定**：宴会厅、酒店客房、解剖室、档案室、沈家老宅、沈氏会议室、游艇、码头、会见室、法庭、墓园。
6. **定妆锁定**：林晚风衣加表，程野白手套加金丝眼镜，宋知远船锚袖扣，不随便换装。沈峥只在照片和闪回里出现，靠疤和表跟程野区分。
7. **避开**：群戏打斗、水下镜头、复杂的手部动作。落海只拍闪回碎片：夜、扳手、水花、袖扣反光，不拍正脸。
8. **台词**：短句，林晚不抬声调。不准用旁白或解说交代真相，真相全靠证据画面。
