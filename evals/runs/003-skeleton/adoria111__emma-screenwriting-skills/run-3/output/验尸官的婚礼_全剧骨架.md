# 《验尸官的婚礼》全剧骨架

60集｜每集1–2分钟｜竖屏｜AI制作｜女频·大女主·复仇悬疑

人物、引擎、结局按选题卡锁定；标【新增】处是本稿补的设计，选题卡里没有。后续分集纲和剧本以本骨架为准。

## 一、两个钩子

- **真钩子**：三年前是谁杀了沈峥？
- **暗钩子**：林晚每赢一步，离“她自己签过的假报告”更近一步。她敢不敢推翻自己？
- 两个问题在第58集庭审同时收口。

## 二、底层真相（编剧掌握，按节点释放）

1. 四年前林晚与沈峥订婚。沈峥出国前把旧机械表留给她：“回来再拿。”【新增】
2. 三年前沈峥查到舅舅宋知远借港口洗钱。游艇夜，宋知远从背后用扳手砸他后脑、推下海；沈砚醉倒在船舱里。
3. 宋知远告诉姐姐是失足落水、尸体没找到。宋婉仪为保股份同意找替身，程野整容受训。
4. 半个月后，一具面部损毁的无名男尸漂上岸。林晚解剖：后脑钝器伤，左手虎口一道旧疤，右拳攥着一枚船锚银袖扣【新增】，结论写“他杀”。周启年收钱拿走袖扣和原始照片，逼她改成“意外”，三天火化。她想到沈峥的疤，打过电话，“沈峥”回了语音（程野在练声），她就信了。她偷偷留下一块组织蜡块【新增】，这是违规，也是她心里那根刺。
5. 程野回国后总戴手套、躲着她，后来当众退婚：宋家要赶走最可能认出他的人。替身回来后，从没问她要过那块表。
6. **倒计时**【新增】：沈峥三十岁生日就是股权交割日，在婚礼后两个月。替身一签字，股份就落进宋知远手里，程野随后“意外”。

| 程野 | 第28集才从林晚口中知道沈峥是被杀的 |
| 沈砚 | 游艇在场的事，第42集才说出口 |

## 四、证据阶梯（全剧引擎）

| 集段 | 林晚拿出的证据 | 沈家怎么毁、怎么抹黑 | 她赢到什么 | 她自己付出什么 |
|---|---|---|---|---|
| 1–10 | 一道疤 | 连夜给程野割出一道疤，当众说她嫉妒发疯 | 当众验出新疤不超过三天 | 要解释疤，就得说出“我在解剖台上见过” |

## 五、阶段走向

**第一段 · 婚礼（1–12）**
- 1：交换戒指，新郎摘下手套，虎口光洁。闪回解剖台上那道疤。定格：真新郎三年前就躺在她的解剖台上。
- 2–5：六层拉扯，一层比一层重：苏曼丽带头骂她晦气 → 宋婉仪轻声请她离场 → 沈砚当众嘲讽 → 她问“疤呢” → 第二天新郎虎口真出现一道疤 → 她当众验出这道疤不超过三天，第一次小胜。
- 6–9：答谢宴上苏曼丽塞来房卡，房里有程野练沈峥签名的本子；本子被烧，苏曼丽被逼反咬她偷窃。周启年警告：“当年你也签了字。”
- **10 付费卡点**：沈家叫她到家宴上对质偷窃。林晚明知会暴露自己，还是说出“三年前那具无名尸就是沈峥，三天火化”。宋婉仪茶盏落地。周启年补一句：“那份意外报告，签的是你的名字。”
- 11–12：宋婉仪为保股份选择压下此事；宋知远以和事佬身份出场。

**第二段 · 切片（13–30）**
- 13–15：停职、档案室失火，官方档案没了。苏曼丽私下来道歉，告诉她交割日，倒计时开始，此后苏曼丽暗中给她递消息。15集尾：她从冷柜深处拿出那块私留的蜡块。
- 16–22：需要沈家的DNA。沈砚不信她，她说出“他从没问过表”。沈砚拿只有兄弟俩知道的小事试探，替身答错，沈砚动摇。
- 23–28：林晚逼近程野。程野承认自己是替身，但不知道死因，他妹妹在宋家手上。28集，林晚告诉他“沈峥是被杀的”，程野明白了自己的下场。
- 29–30 **中点**：沈家拦截送检，最后检测结果：同胞兄弟。沈砚倒戈，成为内应。

**第三段 · 录音（31–44）**
- 31–36：宋婉仪安排了替身，成为头号嫌疑人。宋知远“帮忙”递线索，把怀疑往姐姐身上引。36集对质，宋婉仪崩溃：她只知道是意外。
- 37–40 **至暗**：宋知远许苏家港口生意，苏曼丽反水，交出林晚的申请材料。宋知远抢先举报，林晚被停职调查，切片因来源违规不能作证，交割日逼近。
- 41–42：游艇记录显示沈砚在船上，宋知远暗示是他。沈砚坦白自己醉着、不记得。林晚按伤口推断：凶手从后上方击打，个子高；沈砚被排除。
- 43–44：宋知远对周启年下手，林晚救下他。周启年交出录音，44集尾响起一个温和的声音。

**第四段 · 袖扣（45–55）**
- 45 **大反转**：声音是宋知远。原始照片里死者右拳攥着船锚袖扣；林晚看向他的袖口，一只新一只旧。
- 46–50：宋知远撕下伪装，扣住程野妹妹，安排交割后让程野“意外”。苏曼丽看到账目会拖垮苏家，交出港口出货记录。50集交割仪式上，程野当众拒签：“我不是沈峥。”沈砚在港口救出他妹妹。
- 51–55：宋知远反扑，要灭口林晚。52集宋婉仪得知是弟弟杀了儿子，选择出庭作证。宋知远在港口被捕。

**第五段 · 签名（56–60）**
- 56–58：辩方咬住“你自己签过意外”。林晚当庭交代自己私留蜡块、被逼改结论的经过，补上检材来源链，切片才得以重新作证。她推翻三年前的报告，写下“死者沈峥，他杀”，签上自己的名字。宋婉仪作证，宋知远认罪。
- 59：宋婉仪交出沈氏；程野带妹妹去自首。
- 60：墓前，林晚放下那块表。

## 六、人物主线

- **林晚**：要查清真凶，最大的阻碍是自己那份签名。她从守住秘密，走到当庭认错。
- **程野**：要活下去、救妹妹。从顶着别人的脸苟活，到用自己的名字认罪。
- **沈砚**：从“没人信我”、谁都不信，到成为内应，最后直面游艇那一夜。
- **苏曼丽**：恐惧→求救→为家族生意反水→看清宋知远会拖垮苏家后回头。
- **周启年**：拿钱封口→想用录音保命→被同伙灭口未遂后交出证据。爽点用他的金表：买表日期就是收钱日期。
- **宋婉仪**：为股份压下真相；知道儿子被烧、被弟弟杀害后，交出沈氏。
- **宋知远**：为洗钱杀人，为股份造替身，最后被自己丢掉的那只袖扣钉死。

## 七、写作约束

- 每集都要有一个看得见的证据动作：拿出、被毁或被反咬。换个地点重复同一场争吵，不算升级。
- 沈家的反制轻→中→重：嘲讽→造假→停职→纵火→举报→扣人→灭口。
- 林晚每赢一次，自己的代价就加一分；不写空赢。
- 强卡点：10、15、30、40、45、50、58。下一集前30秒必须兑现上集的钩子。
- **视觉锚点**：林晚的灰风衣和男式旧表，对周启年的金表；程野的白手套（第5集起虎口有疤）；沈砚的黑耳钉；苏曼丽的酒红指甲；宋婉仪的旗袍和珍珠；宋知远的船锚袖扣（新旧之分要单独拍特写）。
- **AI制作**：虎口、切片、袖扣用插入特写；婚礼、庭审这类多人场面拆镜拍，每镜不超过两三人说话。
