# 《验尸官的婚礼》全剧骨架

> 60 集×1–2 分钟｜竖屏｜AI 仿真人。分集大纲与剧本不得与本骨架冲突。

## 一、核心契约

- **观众承诺**：每集林晚亮出一样看得见的证据，打沈家一次脸；每赢一次，离凶手近一步，也离她自己的签名近一步。
- **季问题**：三年前是谁杀了沈峥？林晚敢不敢推翻自己签的报告？
- **为什么不能一次掀牌**：尸体三天内已火化；“意外”结论上签的是她自己的名字，真相一揭，第一个被追责的是她。
- **新鲜变量**：复仇者手里也握着一份假报告。证据越完整，她越接近自首。

## 二、逻辑护栏（已定稿，写作不得违背）

1. 三年前尸体泡海、面部损毁，“沈峥”又在国外“养病”、还给她发过消息；虎口疤不罕见，她当时没起疑。
2. 程野回国后借病疏远她，一年后退婚。“晦气”只是借口，真正的原因是宋婉仪怕法医看穿替身。
3. 宋家知道那道疤，让程野公开场合戴手套；交换戒指必须摘手套，破绽由此出现。
4. 那块旧表是沈峥订婚时送她的。婚礼上“新郎”看见它毫无反应，这是第二个破绽。
5. 尸体手里攥着一枚船锚袖扣，被周启年私藏，用来牵制宋知远；宋知远现在那对袖扣有一枚是新配的。

## 三、证据引擎（每集必守）

1. 每集至少一样**能拍特写**的证据（疤、伤、切片、文书、签名、录音、物件），不能只靠台词。
2. 证据走三步：出示 → 沈家毁证或抹黑 → 林晚用专业换路拿回或反证；同一种毁证手段不连用两次。
3. 每次胜利推进 A 线“谁杀了沈峥”或 B 线“我签的报告”，每 5 集两线都要动。
4. 每个小弧收尾，至少一件证据存进终审证据链，被毁的不算。
5. 林晚只凭证据说话，不靠直觉，不靠别人救场。

## 五、五段结构

**第一段 · 婚礼（1–12）**｜对手：苏曼丽与沈家亲戚｜R0–R1
- 1–3 Pilot：第 1 集，她被当众嘲笑是“晦气前任”；新郎摘手套交换戒指，虎口没有疤，她想起三年前解剖台上那道疤。第 2 集，她用一个法医细节当场反击苏曼丽，随后被赶出婚礼。第 3 集，答谢宴上苏曼丽塞给她求救房卡：踩她的人，在向她求救。
- 4–8：房里见程野耳后整容疤，替身确认。档案照片已被抽走，她用私存照片入链。沈砚登场，不信她。
- 9–12：中心档案“失火”；沈家买通媒体称她“嫉妒成疯的前任”，周启年借机停她的职。关门：替身确认；开门：死者是谁？

**第二段 · 死者是谁（13–30）**｜对手：宋婉仪＋周启年｜R2–R3
- 13–18：停职后在体制外查。沈砚由疑转帮，DNA 确认死者是沈峥，沈砚崩溃。
- 19–24：查程野身份：赌债、整容、被控制的妹妹。宋婉仪用钱和舆论围剿她，并派人销毁切片。
- 25–30：沈峥三十岁的股权交接会定为倒计时。中点（30）：林晚当众让“新郎”摘下手套，替身曝光。爽债 D1 回收：当年退婚的根本不是沈峥。**错胜**：舆论认定宋婉仪害死儿子、找替身骗股权，宋知远“大义灭亲”，接管沈氏。集尾，他和林晚握手，袖扣一新一旧。

**第三段 · 凶手会学习（31–45）**｜对手：周启年→宋知远｜R4
- 31–35：林晚主动设局，录下周启年承认受贿，金表当众被扒。周启年反咬：录音同样证明她签了字。她被立案调查，B 线第一次见血。
- 36–42：宋知远抢先伪造证据，把凶手指向那晚醉酒的沈砚；苏曼丽为家族生意反水，作证沈砚当晚和哥哥吵过架。沈砚被抓，林晚失去内应。
- 43–45：她用伤口测量证明凶器是扳手、凶手比沈砚高，沈砚获释。宋知远第一次被怀疑。

**第四段 · 游艇夜（46–55）**｜对手：宋知远｜R5
- 46–49：程野想起当年找他整容的是宋知远，成了下一个“意外”目标；林晚救下他，换来出庭作证的承诺。
- 50–52：周启年在看守所遇险，交出藏了三年的袖扣；宋婉仪得知杀子的是亲弟弟，倒戈。
- 53–55：苏曼丽发现宋知远要让苏家顶洗钱的罪，交出港口账目，D5 回收。

**第五段 · 她的签名（56–60）**
- 56：宋知远提出交易：抹掉她的签字记录、恢复职务，换她撤回证据。三年前周启年接受的正是这种交易。她拒绝。
- 57–59：庭审中宋知远以她签过假报告为由，申请排除她全部证据；她当庭承认受迫签字，推翻原报告。
- 60：她重新写下“死者沈峥，他杀”，签上自己的名字。宋知远认罪，宋婉仪交出沈氏，程野带着妹妹去自首。墓前，她放下那块表。

## 六、四条阶梯

- **揭露**：R0 新郎是替身（1）→ R1 私存照片证实无名尸有疤（6）→ R2 死者是沈峥（18）→ R3 替身公开（30）→ R4 凶器是扳手，凶手不是沈砚（44）→ R5 宋知远洗钱杀人（55）。
- **对手**：苏曼丽（近身羞辱，12）→ 宋婉仪（守家族秘密，52 倒戈）→ 周启年（制度守门人，也是她的镜像：同一份报告，相反的选择，35）→ 宋知远（幕后，60）。
- **能力**：看出破绽（1）→ 用专业赢下一局（2–18）→ 主动设局（31）→ 保护他人（46）→ 拒绝捷径（56）。
- **代价**：停职（12）→ 被立案调查（35）→ 失去内应（42）→ 当庭自认（59）。

## 七、人物弧

| 人物 | 错误信念 → 结局选择 | 底线／学习 |
|---|---|---|
| 林晚 | “我是被逼的，所以签字不算我的” → 亲手推翻、亲手重签 | 只认证据，包括对自己不利的证据 |
| 程野 | “活下去就得当别人” → 以自己的名字自首 | 妹妹是他唯一的软肋 |
| 沈砚 | “那晚我什么都不记得” → 面对自己的醉酒 | 由嘲讽者变内应，被冤不退出 |
| 苏曼丽 | “家族生意高于一切” → 反水一次后交出账目 | 只反水一次，第二次选择自己 |
| 宋婉仪 | “儿子是意外死的，保住股份就是保住他” → 交出沈氏 | 绝不伤害儿子 |
| 周启年 | “收钱改个字，不算杀人” → 遇险后交出袖扣、出庭作证 | 怕死胜过怕丢脸 |
| 宋知远 | “我在替沈家赚钱” → 认罪伏法 | 毁证→伪证→嫁祸→灭口→收买，每次换招 |

## 九、分集与 AI 生产约束

- 每集只有一个主转折；集尾钩子在证据出现、身份相撞、错胜、倒计时、情感真相之间轮换，“大人物到门口”全剧最多三次。
- 固定资产 ID：林晚的风衣和旧表、程野的白手套（30 集后不再戴）、沈砚的耳钉、宋知远的袖扣（一新一旧）、周启年的金表。沈峥与程野同脸，回忆戏用冷色调和虎口疤区分。
- 解剖戏不拍血腥全尸，只用切片、照片、遮尸布、器械特写。
