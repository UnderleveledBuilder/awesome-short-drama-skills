# 《验尸官的婚礼》全剧骨架

> 国内剧 · 原创 · 9:16 竖屏 · 60 集 × 60–120 秒 · 女频大女主 / 复仇悬疑 / 豪门
> 用途：管住分集大纲和剧本。下游可以加戏，不能改这里的因果、真相和结局。

## 一、一句话

被退婚的女法医林晚在前未婚夫的婚礼上认出新郎是替身，她要一件件拿出证据，证明三年前那具被她签成“意外”的无名男尸就是沈峥；每往真相走一步，她自己签的那份假报告就离法庭更近一步。

## 二、全剧只回答四个问题

- **外部**：谁杀了沈峥？答案：宋知远。
- **内心**：林晚一直以为“那次是被逼的，抓到凶手就算还清”。全剧逼她认清：签了名就得担责，要还清，只能自己当庭推翻自己。
- **关系**：沈砚从不信她到成为唯一内应；宋婉仪从仇人变成证人。
- **规则**：尸体早已火化，没法复检。她只能靠留下来的东西（疤的记录、私留的切片、原始照片、登记簿、录音），而每用一件都要付代价。

## 三、真相底账（编剧先全知道，观众按幕拿到）

1. 沈峥发现舅舅宋知远借沈氏海外港口洗钱。
2. 游艇夜，宋知远用扳手砸了沈峥的后脑，把人推下海。挣扎时沈峥扯下他一枚船锚银袖扣，攥在手里。沈砚醉倒在船舱，什么都记不清。
3. 数日后尸体冲上岸，脸被礁石毁了，作为无名尸送检。林晚判“他杀”，在报告里写了“左手虎口陈旧疤”，物证登记簿上记了“银色袖扣一枚”。周启年收了宋知远的钱，抽走袖扣，逼她改成“意外落水”，三天内火化。林晚违规私留了一份组织切片，这是她唯一的底牌，也是她的把柄。
4. 宋婉仪只知道儿子“落水失踪”。为了保住遗嘱里的股份，她接受弟弟的安排，让程野整容顶替。她不知道尸体找到过、也火化了。
5. 宋知远手里攥着程野的妹妹，靠她控制程野。
6. 一年前，宋婉仪怕当法医的未婚妻看出破绽，让“沈峥”当众退婚。

## 四、五幕大弧

**第一幕 · 婚礼识替（1–10 集）**
- 目标：证明新郎不是沈峥。
- 证据：缺了的那道虎口疤 → 婚书签名（像得过头，连沈峥写错的那一笔都改对了）→ 苏曼丽塞来的房卡，房里有程野整容前的照片。
- 反制：宋婉仪轻声一句，林晚被保安拖出去；“前任嫉妒大闹婚礼”上了热搜；周启年以“精神状态”为由停了她的职。
- 出口（第 10 集卡点）：程野摘下手套承认“我不是他，我不知道他在哪”。林晚说：“我知道。他三年前躺在我的台子上。”

**第二幕 · 无名尸回家（11–24 集）**
- 目标：证明无名尸就是沈峥。
- 证据：私留的切片 → 跟沈砚做亲缘比对 → 原始解剖照片（后脑钝器伤）。
- 反制：周启年在送检时调包样本，她拿另一半切片去外地重做；周又举报她违规留存，沈家告她诽谤。
- 关系：沈砚从骂她“拿我哥炒作”，到亲手拔下自己的头发递给她。
- 中段反转（第 24 集）：比对成立，沈峥确实死了。同一天，周启年把那份签着“林晚”的意外报告扔上网：“结论是你自己签的。”她从原告变成被告。

**第三幕 · 母亲（25–36 集）**
- 目标：让宋婉仪开口，交代替身是谁安排的。
- 证据：遗嘱股份条款 → 整容医院记录 → 周启年金表的付款记录（付款账户属于沈氏海外业务，林晚误以为是宋婉仪付的）。
- 反制：宋婉仪护着股份，推动法医中心开除林晚；苏曼丽为了港口合同反水，把计划卖给沈家，切片原件被毁。
- 爽点：林晚用金表和转账当众拆穿周启年，周启年被停职调查。
- 幕高潮：林晚把比对结果放到宋婉仪面前：她以为还在海上的儿子，三年前被当作无名尸解剖、火化。宋婉仪崩溃，认下“替身是我安排的”，却坚持“落水是意外，知远告诉我的”。
- 出口：周启年取保期间坠楼，结论又是“意外”。

**第四幕 · 游艇（37–48 集）**
- 目标：找出游艇上的凶手。
- 证据：物证登记簿复印件上的“银色袖扣一枚”→ 宋知远袖口两枚袖扣一新一旧 → 程野留作保命的录音：“哪天你没用了，也会意外。”→ 沈砚想起来的扳手声。
- 反制：一直帮着林晚的“好舅舅”翻脸，拿程野妹妹逼程野反咬林晚，又买通舆论把周启年的死栽到她头上。
- 关系：沈砚说出自己瞒了三年的事：那晚他在船上，喝醉了，什么都没做。
- 幕高潮：林晚故意放出“还有最后一份切片”，引宋知远动手销毁，人赃并获；程野妹妹获救，程野倒戈。
- 出口：宋知远说：“开庭可以。她三年前签的字，够她自己坐牢。”

**第五幕 · 签名（49–60 集）**
- 目标：定宋知远的罪，同时推翻自己签过的报告。
- 反制：辩方只打一点：“鉴定人自己签过意外，她的话不可信。”
- 证据链当庭串起来：疤 → 切片 → 照片 → 袖扣 → 录音 → 港口账。
- 爽点：宋婉仪当庭作证、交出沈氏；苏曼丽交出港口账；程野带着妹妹自首。
- 全剧高潮：林晚当庭陈述“三年前那份报告是我签的，是假的”，重新写下“死者沈峥，他杀”，签上名字，接受对自己的追责。宋知远认罪。
- 终场：墓前，她把那块表放下。

## 五、证据推进规则

- 每集结尾，她手里必须多一样能特写的东西，或者刚失去一样。
- 证据不白给：拿到 → 被毁或被抹黑 → 换个办法补回来。
- 证据按层升级：身体（疤、指纹）→ 样本（切片、头发）→ 记录（照片、登记簿、转账）→ 声音（录音）→ 人证 → 她自己的签名。
- 每赢一次，要同时离假报告更近一步：一句追问、一条热搜、档案柜里那份报告的特写都行。

## 六、人物走向与红线

- **林晚**：冷静 → 被逼认罪 → 自己推翻自己。不哭着求人信她，不靠男人解围，不原谅凶手。
- **沈砚**：不在乎 → 唯一内应。感情最多写到并肩，不写恋爱兑现。
- **程野**：怕死的替身 → 自首。白手套是他的标志，摘手套就是说真话。
- **苏曼丽**：踩人 → 暗中递房卡 → 反水 → 交账。反水必须有生意上的理由。
- **宋婉仪**：拿儿子换股份的母亲 → 证人。她不知道儿子是被杀的。
- **周启年**：第三幕落马，幕末“意外”身亡。
- **宋知远**：前三幕是和气可靠的舅舅，可以帮林晚一两次；第四幕揭底。

## 八、伏笔与回收

- **船锚袖扣**：第 1 集婚礼上宋知远整理袖口，只当他的标志 → 第四幕登记簿回收。
- **旧机械表**：第 1 集特写磨白的表带 → 第三幕交代是沈峥订婚时送的 → 终场放在墓前。
- **签名**：第 1 集林晚在婚礼礼簿上签名 → 第 24 集假报告上的签名 → 第 60 集重写报告时的签名。
- **程野的妹妹**：第一幕程野接电话说“别怕，哥在”→ 第四幕成了人质 → 结局一起自首。
- **周启年的金表**：第一幕特写 → 第三幕拆穿。

## 九、钩子与卡点

- 第 1 集前 3 秒：婚礼进行曲里，她说“新郎不是沈峥”。
- 大卡点：第 10、24、36、48、59 集。
- 每集结尾要么新证据到手，要么证据被毁，不许用半句话断开。

## 十、为 AI 拍摄做的约束

- 主场景控制在 7 个：婚宴厅、解剖室、法医中心档案室、沈宅客厅、游艇、法庭、墓园。
- 闪回只用三年前的解剖室，固定冷白光，和现在的戏一眼区分开。
- 每集主要出场不超过 4 人；证据都要能单独拍特写。

## 十一、禁改项

- 凶手只有宋知远；宋婉仪没有参与杀人。
- 假报告必须由林晚自己当庭推翻，不能让别人替她洗白。
- 结局照选题卡执行，不改。
