# 《验尸官的婚礼》全剧骨架

> 60集｜竖屏｜单集1–2分钟｜AI拍摄｜女频·大女主·复仇悬疑·豪门
> 本骨架只定方向，后续分集大纲与剧本必须服从它。

## 一、故事内核

**一句话：** 被退婚的女法医在前任婚礼上认出新郎是替身，用一件件证据把三年前那具"意外"男尸翻成"他杀"，最后推翻的是她自己签下的名字。

**核心冲突：** 外部是林晚要证明沈峥被杀，沈家要守住替身和股份；内部是她每赢一步，就离自己签的假报告更近一步。想赢，先得认错。

**背景：** 当代沿海港城。沈氏和苏家合做港口生意，宋知远管海外港口。周启年在法医中心一手遮天。

**前史（不正面演，只用闪回）：**
- 四年前：林晚与沈峥订婚，沈峥把戴了十年的机械表给了她。
- 三年前：沈峥发现舅舅宋知远借港口洗钱，在游艇上被扳手砸中后脑、推下海，挣扎中扯下宋知远一枚船锚袖扣。沈砚醉倒在船舱。
- 数日后：一具面部损毁的无名男尸上了林晚的解剖台。她写"他杀"，记下"左手虎口陈旧疤""右手攥金属袖扣"。周启年改成"意外"，逼她签字，三天火化，袖扣"遗失"。她偷偷留下一块病理蜡块。
- 同期：宋婉仪以为儿子是落水意外，为保住遗嘱股份，让程野顶替，对外称"国外养病归来"。
- 一年前：宋婉仪怕法医儿媳看穿，授意"沈峥"当众退婚。

## 二、三幕结构

### 第一幕·认尸（1–12集）起势段
- **1–3**：婚宴上苏曼丽当众羞辱林晚。交换戒指时新郎白手套滑落，虎口光洁，闪回解剖台上那道疤。林晚："新郎不是沈峥。真的沈峥，三年前躺在我的解剖台上。"她被架出去，热搜骂她"疯前任"。
- **4–7**：林晚问"新郎"那块表的来历，他答不上；苏曼丽栽赃她偷婚戒，她凭指纹位置当场反证。答谢宴上苏曼丽偷塞房卡："他不是我丈夫，救我。"
- **8–12**：靠房卡拿到程野的头发，DNA比对需要沈砚，沈砚冷笑拒绝。周启年把她调离岗位，封存旧档。**10集卡点。** 12集林晚取出藏了三年的蜡块，故事转向"证明死者是谁"。

### 第二幕上·拔刺（13–28集）攀升段
- **13–17**：沈砚说出三年来的怀疑："哥回来以后，再没叫过我小名。"他交出血样，成为沈家内应。
- **18–20**：蜡块DNA与沈砚是同胞兄弟。**20集卡点。**
- **21–25**：沈家买黑稿抹黑她。宋知远以"好舅舅"身份递来周启年金表的购买记录，付款账户指向宋婉仪，故意误导。林晚决定拿出藏了三年的录音：周启年逼她签字的原声里，也有她那句"我签"。
- **26–28**：专家复核会上当众放录音，周启年倒台（中反派落幕）。**28集卡点。**

### 第二幕下·风暴（29–48集）风暴段
- **29–33**：林晚被停职立案。沈砚与她和解："至少你写过一次他杀。"林晚查到程野的整容记录和赌债，得知宋家拿他妹妹做筹码。
- **34–36**：周启年取保后"心梗意外"死亡。林晚指导徒弟复检，发现颈后针孔，坚持写"他杀"。三年前没做到的，这次做到了。
- **37–38**：家宴摊牌，程野当众摘下白手套。**38集卡点。**
- **39–44（全剧低谷）**：凶器扳手"出现"，上面有沈砚指纹，沈砚被带走；苏曼丽为港口生意反水，把林晚的原始报告草稿交给宋知远；林晚伪证案即将开庭。最低点压在42–44三集。
- **45–48**：林晚翻出旧工作相机的备份，死者右手攥着船锚袖扣。特写宋知远袖口，两枚袖扣新旧色差。宋婉仪看到照片崩溃；沈砚想起醉梦里"舅舅"的声音。**47集卡点。** 48集宋知远撕下和气的脸。

### 第三幕·重签（49–60集）决战段
- **49–52**：林晚复检扳手，沈砚的指纹叠在三年锈层之上，是后按的，沈砚洗清。程野交出偷录的宋知远原话（"演到死为止"），妹妹获救。苏曼丽回头交出港口洗钱账目，宋婉仪交出遗嘱和替身协议。
- **53–56**：庭审。辩方攻击："一个签过假报告的法医，凭什么信她？"**56集卡点。**
- **57–58（全剧最高潮）**：林晚当庭承认签过字，推翻原报告，重新写下"死者沈峥，他杀"并签名；袖扣、扳手、账目、证言全部对上，宋知远认罪伏法。
- **59**：宋婉仪交出沈氏，程野带妹妹自首，林晚接受处分。
- **60**：墓园。林晚把那块表放在沈峥墓前。

## 六、铁律（约束后续大纲与剧本）

1. **一集一证**：每集一件能拍成特写的证据（疤、表、切片、录音波形、袖扣）；每赢一次，都把林晚自己的签名往前推一步。
2. **沈家每集反手**：毁证、抹黑、收买、威胁，不让林晚白赢。
3. **信息闸门**：替身第1集交底；死者身份20集坐实；凶手45集才揭。此前袖扣只给特写不解释，宋知远前期必须像好人。
4. **大女主底线**：翻盘靠专业，不靠运气，不违法取证；她的错由她当庭认下，不洗白。
5. **合规**：尸体与创口不拍正面，用报告、打码照片、器械声代替；暴力只拍结果；赌债、整容不美化。
6. **AI拍摄**：主场景限定为婚宴厅、解剖室、沈宅、游艇、法庭、墓园；每集主要角色不超过4人；人物锚点固定（林晚灰风衣+旧表，程野白手套+金丝眼镜，沈砚黑耳钉，苏曼丽酒红指甲，周启年金表，宋婉仪旗袍珍珠，宋知远船锚袖扣）。沈峥闪回和程野同脸，用"有疤、戴表、不戴手套"区分。
