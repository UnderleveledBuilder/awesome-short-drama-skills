# 《验尸官的婚礼》全剧骨架

60集竖屏｜每集1–2分钟｜AI拍摄｜女频·大女主·复仇悬疑·豪门

## 一、总纲

- **核心问题**：三年前是谁杀了沈峥？
- **主角的代价**：她每靠近真相一步，也就离自己签的那份“意外”报告更近一步。全剧真正的终点不是抓到凶手，是她亲手推翻自己签的报告。
- **每集都要走的循环**：林晚亮出一样看得见的证据 → 沈家或周启年毁掉它、抹黑她 → 她靠专业把证据救回来，或者换出下一样 → 离真相近一步。
- **倒计时**：沈峥三十岁生日当天接手沈氏一半股份（第30集）。沈家必须让“沈峥”撑过这一天。

## 二、前史（给编剧看，前10集不讲透）

三年前的游艇夜，沈峥发现舅舅宋知远借港口洗钱，被宋知远用扳手砸了后脑，推下海；沈砚也在船上，喝醉了。上船前一天，沈峥把自己戴了多年的表交给林晚：“替我戴几天。”
两周后一具无名男尸被冲上岸，脸已毁。林晚解剖时记下三处：后枕条形凹陷骨折、左手虎口旧疤、右掌心一道船锚形压痕，结论写“他杀”。周启年收了宋知远的钱，逼她改成“意外”签字，三天内火化。原始照片和一套蜡块，她私下留了一份。
宋知远告诉姐姐，沈峥是喝多了失足落水。宋婉仪对外说儿子“出国养病”，找来程野整容顶替。一年前，“沈峥”当众退婚，还向她讨回那块表。退婚的真正原因是她太熟悉沈峥，迟早会认出假的。

## 三、证据阶梯（每集的小证据都挂在这五级上）

| 段 | 主证据 | 证明什么 | 对方怎么毁 |
|---|---|---|---|
| 1 | 疤：新郎虎口光洁，后来又画了一道假疤 | 新郎不是沈峥 | 删光订婚照，剪辑“前任大闹婚礼”视频 |
| 2 | 切片：私留的蜡块，加沈砚的血做亲缘鉴定 | 无名男尸就是沈峥 | 收买化验室，举报她私藏尸体组织 |
| 3 | 金表与录音：周启年的购表凭证，苏曼丽录下的新婚夜通话 | 替身是有人安排的 | 停她的职，要送她做精神鉴定 |
| 4 | 袖扣：尸检照上的掌心压痕对上宋知远的船锚袖扣，原件锁在周启年的保险柜里 | 谁动的手 | 烧掉蜡块，给程野制造“意外” |
| 5 | 表：机芯背后藏着沈峥留下的存储卡 | 为什么杀他 | 宋知远从港口出逃 |

## 四、分段走向

**第一段 婚礼认人（1–10）**
- 第1集：交换戒指时新郎摘下手套，虎口光洁。林晚想起解剖台上那道疤。集尾一句：“真新郎，三年前就躺在我的解剖台上。”
- 她试探“沈峥”，问一件只有他俩知道的事，他答错了。沈家把她轰出门，剪辑视频让全网骂她嫉妒发疯；周启年顺势停了她的职。
- 第9集答谢宴：宋婉仪让新郎当众亮出虎口的“旧疤”来打她的脸。林晚拿一块酒精棉擦过去，疤掉了，是画的。这是全剧第一次当众打脸。
- 第10集（第一个付费卡点）：苏曼丽偷偷塞来房卡。套房里她放出新婚夜的录音，新郎对着电话哭：“我叫程野，我不想死。”

**第二段 切片验亲（11–20）**
- 林晚取出私藏三年的蜡块和照片。这是违规留下的，也是她心里那根刺。
- 要证明尸体是沈峥，得拿到沈家人的DNA。沈砚不信她，她把程野露出的破绽一样样摆给他看。第15集（全剧1/4）：沈砚伸出胳膊让她抽血，成了她在沈家的内应。
- 沈家收买化验室，又举报她私藏尸体组织；她只能半夜潜回法医中心，自己做比对。
- 第20集：亲缘报告出来，两人是同胞兄弟。周启年站在她身后：“公开它，就等于告诉所有人，三年前是你签的字。”

**第三段 交接日（21–30）**
- 周启年拿她的签名当绳子勒住她。她反查周启年那块金表的来路，在中心例会上当众摆出购表凭证：日期是结案后第三天。周启年被停职调查，这是打在他脸上的第一次。
- 程野动摇了，想跑，被宋婉仪拿他妹妹拴住。
- 第30集（中点）：沈峥三十岁生日，也是股权交接仪式。林晚当众摆出亲缘报告：“三年前躺在我解剖台上的那个人，才是沈峥。”交接当场叫停，宋婉仪当众瘫坐，这是打在沈家脸上的一次。
- 中点反转：警方调出旧档，那具尸体的结论是“意外落水”，签名是林晚。她揭穿了替身，自己签的报告却成了凶手的护身符。宋知远以“最可靠的舅舅”身份出面收拾残局，弯腰替她捡起笔，袖口露出一枚船锚袖扣。

**第四段 推翻“意外”（31–45）**
- 风向变了：“她当年自己签的意外，现在翻案，是报复退婚。”她因私藏尸体组织被立案调查。
- 她准备用剩下的蜡块做硅藻检验，证明沈峥入水前就已经死了。宋知远一边给她递资源，一边布局。第40集，苏曼丽为保住苏家的港口合同反水，泄露了蜡块的藏处，蜡块被烧；程野随后“意外”坠楼，重伤。
- 第41–42集是低谷：证据没了，她被带走。沈砚把她保了出来。
- 沈砚拼起那晚醉酒后的碎片记忆：那晚过后，舅舅换了一对袖扣。林晚拿尸检照上的掌心压痕一对，锁定了宋知远。
- 第45集（全剧3/4）：她逼周启年看清，宋知远下一个“意外”就轮到他。周启年为了保命，交出保险柜里的原件袖扣和当年受贿的录音。凶手坐实。

**第五段 庭审（46–60）**
- 宋婉仪知道儿子死在弟弟手里，三年来她护着的，是杀子的仇人。
- 第48集：那块走了三年的表停了。修表师从机芯背后取出沈峥藏的存储卡，里面是港口洗钱的账目，就是他被杀的原因。原来把表交给她的那天，他已经想到自己可能回不来。
- 宋知远走港口出逃，扣下程野的妹妹。苏曼丽这次没再站错，交出了船期（她只反水那一次）。林晚带警方截船，第54集宋知远落网。
- 庭审（56–59集）：辩方拿出唯一的官方结论“意外”，上面是她的签名。周启年当庭翻供，被自己的录音打脸，这是第二次。林晚当庭承认三年前那份报告是假的，重新写下“死者沈峥，他杀”，签上自己的名字。宋知远认罪，宋婉仪交出沈氏，程野带着妹妹去自首。
- 第60集：墓园，她把修好的表放在沈峥墓前。

## 五、人物弧线

- 林晚：只认证据不认人 → 到最后连自己也不放过。
- 沈砚：不信她 → 当她的内应 → 找回那晚的记忆，不再装作什么都不在乎。
- 苏曼丽：带头踩她 → 向她求救 → 为家里反水 → 交出船期。
- 程野：替别人活着 → 想逃 → 站出来作证。
- 宋婉仪：保股份 → 发现保住的是仇人 → 交出沈氏。
- 周启年：施压的人 → 被当众收拾两次（第26、57集左右）。
- 宋知远：最可靠的舅舅 → 到最后才翻面。

## 六、分集写作守则（后面的分集大纲和剧本都照这个走）

1. 每集要有一个能给特写的证据，或者证据的变化（出现、被毁、被救回）。开头3秒接上集的钩子，结尾必须留钩子。
2. 对方的反制手段轮着用：毁物、抹黑、收买、拿制度压人、制造意外。同一种手段不连着用两集；制造意外只归宋知远。
3. 打脸只落在沈家和周启年脸上。林晚靠专业赢，配角只负责递资源、当见证，不替她揭底。
4. 各阶段不能提前放出来的：第20集前不确认尸体身份；第30集前不公开替身；第30集集尾前，宋知远只演和气舅舅；第45集前林晚不知道凶手是谁；第46集前宋婉仪一直以为儿子是意外；第58集前不当庭推翻报告。
5. 伏笔：表（第2集被讨要，第48集停走，第60集放到墓前）；掌心压痕（第11集埋，第45集收）；后枕骨折（第11集埋，庭审时对上扳手）；程野妹妹（第16集埋，第52集收）；苏家港口（第10集埋，第40、52集收）。
6. AI拍摄：主场景只用婚宴厅、解剖室、档案室、沈家客厅、酒店套房、游艇（只在回忆里）、法庭、墓园。一场戏同框不超过3人。沈峥只在回忆里单独出镜，靠虎口的疤和那块表跟程野区分。回忆戏统一冷蓝色调。少打斗，不拍水下戏，冲突靠对峙和亮证据。人物造型照选题卡锁死。
