# 《验尸官的婚礼》全剧骨架

60 集竖屏 · 每集 1–2 分钟 · AI 生成 · 女频大女主 / 复仇悬疑 / 豪门

## 一、核心

被退婚的女法医在前未婚夫的婚礼上认出新郎是替身，用一件件看得见的证据把三年前那具无名男尸还原成沈峥，最后亲手推翻自己签过的假报告。

- **主线**：三年前是谁杀了沈峥。
- **副线**：林晚自己签的那份“意外”报告。越接近凶手，越接近她自己的罪。
- **终点**：不是夺回沈氏，是她当庭重写“死者沈峥，他杀”，签上自己的名字。

## 二、推进规则（管住分集和剧本）

1. **每集一件看得见的证据**。全剧分五段，每段换一类主证：疤 → 切片 → 报告 → 录音 → 袖扣。
2. **沈家毁证逐段升级**：抹黑 → 毁样本 → 停职 → 灭口 → 杀人。
3. **爽点只落在沈家人和周启年脸上**。林晚不抬声调，靠证据赢。
4. 每集结尾必须留一个钩子，相邻两次爽点之间最多隔 3 集。

## 五、人物（14 位）

**主角组（4）**
- **林晚**：从被退婚、被停职，到当庭推翻自己签的报告。赢回的是那份签字。
- **程野**：从替死人活着，到交出手册作证，再到带妹妹自首。
- **沈砚**：从不信法医，到用自己的血做比对，再到想起游艇那晚、出庭作证。
- **宋知远**：前半程是和气的调停人，第 33 集袖扣露底，第 53 集在同一艘游艇上被拿下。

**重要配角（5）**
- **苏曼丽**：踩人 → 塞房卡 → 第 36 集前反水 → 第 48 集回头。
- **周启年**：被反将、被灭口未遂，交出录音认罪。
- **宋婉仪**：一路护着替身，第 45 集崩塌。
- **沈峥**：只出现在闪回里，和程野共用一张脸，靠虎口的疤区分。
- **程溪**（新增）：程野的妹妹，宋知远手里的筹码，替代原来的赌债线。

**功能性角色（5）**：刑侦队长、实习法医、宋家保镖、婚礼司仪、审判长。

## 六、取舍

- **砍掉的线**：港口商战（港口只作为证据来源）、林晚和沈砚的感情线（大女主，不谈恋爱）、二房争股（只当宋婉仪找替身的动机）、程野的赌债债主（换成妹妹当筹码）。
- **合并的人**：宋家的司机、打手和买通的鉴定人并成一个保镖；警察并成一位刑侦队长；法医中心同事并成一位实习法医。
