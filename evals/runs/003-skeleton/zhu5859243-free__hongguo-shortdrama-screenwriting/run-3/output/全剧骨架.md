# 《验尸官的婚礼》全剧骨架

**定位**：女频大女主·复仇悬疑｜竖屏 60 集｜每集 90～120 秒、≤2 场｜AI 拍摄
**流派**：情绪流为主，悬疑副线走剧情流（谁杀了沈峥）。

## 一、主线

**一句话故事**：被退婚的女法医林晚，要推翻自己三年前签的“意外”报告，证明死者是沈峥、死于他杀；沈家拼命保替身保股份，真凶是全家最信任的舅舅，最硬的阻碍是报告上她自己的签名；她手里只有火化没烧掉的东西：一道疤、一张切片、一段录音。

**情绪契约**（全剧不换）：证据一摆，说谎的人就得改口，包括三年前的她自己。

**大期待**（第 2 集前说死）：林晚：“那份报告是我签的。我亲手改回来。”

## 二、铁设定（后续不得违背）

1. **时间线**：四年前订婚。三年前游艇夜，沈峥把旧表交给林晚，说“明天跟你说件事”；当晚宋知远用扳手砸他后脑、推下海，再告诉姐姐是醉酒落水。数日后无名男尸进法医中心：面部被礁石损毁、无证件，左手虎口旧疤，枕骨凹陷骨折。林晚初判他杀，周启年逼改“意外”，三天火化。沈家称沈峥“出国养病”，程野随后顶替回国。一年前宋家授意退婚，真因是她是唯一认得出替身的人。
2. **倒计时**：婚礼为“交割日”（沈峥三十岁生日，婚后约一月）铺路，程野签完股权交割就没用了。
3. **证据来源**：尸体已火化，只用留存物（照片、切片/蜡块、X 光、笔记、录音、物证）。全剧不出现开棺、验尸。
4. **办案边界**：林晚不私自侦查、不越权取证，关键证据移交警方或走复核程序。
5. **虎口疤**：沈峥小时候替沈砚挡碎玻璃留下的，只有沈砚知道来历。
6. **袖扣**：死者手里攥着一枚船锚袖扣，接收尸体时就被周启年截下私藏当保命符，林晚从未见过。

## 四、钩子网

- **大情绪点**：1 疤｜10 门开｜18 同胞｜22 签名｜26 知凶｜34 落网｜43 二选一｜50 录音｜55 袖扣｜59 改报告｜60 放表
- **信息差**：1–25 林晚知、配角不知（打脸）→ 26–42 观众知、林晚不知→ 43–60 双方都知，宋知远不知底牌（清算）
- **袖扣埋点**：26 集前入画 ≥3 次，都在证据出事现场

## 五、人物弧光与配额

- 林晚：认证据不认人 → 先认自己的错 → 当庭签回自己的名字
- 沈砚：不信她 → 内应 → 交出瞒了三年的秘密
- 程野：扛着装 → 怕“意外” → 自首
- 苏曼丽：踩她、暗中求救 → 反水 → 撤证
- 宋婉仪：护替身 → 被怀疑 → 知道丧子真相，交出沈氏
- 宋知远：和气舅舅 → 暗手 → 伏法
- 周启年：压她 → 落网 → 立功作证
- **新增角色**：程溪（22 岁，19 集首出）、陈警官（23 集首出）；有名字角色 ≤10 人
- **感情线**：不设恋爱主线；林晚与沈砚只到“并肩”，与程野零暧昧，避开替身文学

## 六、写作铁律（管住分集和剧本）

1. **一集一证**：每集至少一件证据特写入画，按台账编号；旧证据再出场必须带新信息。
2. **每证必反制**：对手必毁、抢或抹黑；林晚回击必带新信息、新行动或新代价，禁止复读。
3. **单元闭环离她的签名更近一步**：A 报告甩脸，B 自揭其短，C 当庭改写。
4. **宋知远**：42 集前林晚不得怀疑他。
5. **合规**：周启年的腐败只写个人行为并受惩处，警方和复核程序公正；暴力只拍声音、物件、结果；解剖只拍照片、切片、X 光、报告，不拍尸身。
6. **AI 拍摄**
   - 主场景锁 8 个：宴会厅、法医中心、周启年办公室、沈家客厅、酒店房间、林晚公寓、法庭、墓园。
   - 游艇只做 3～5 秒夜色碎片闪回。
   - 人物标志物不换：灰风衣男表、金丝眼镜白手套、黑耳钉、酒红指甲、金表、旗袍珍珠、船锚袖扣。
   - 虎口、袖扣用固定机位单独插入镜头，防手部崩坏。
   - 群演虚化，前景说话的人不超过 4 个；台词用短句。
