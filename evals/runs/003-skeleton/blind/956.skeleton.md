# 《验尸官的婚礼》全剧骨架

60 集竖屏 · 每集 1–2 分钟 · AI 拍摄 · 女频大女主复仇悬疑

## 一、主线与底牌

- **外线问题**：三年前是谁杀了沈峥？
- **内线问题**：林晚敢不敢推翻自己签过的那份假报告？
- **咬合规则**：外线每赢一步，内线就多付一份代价，最后一幕两条线在法庭上一起收。
- **真相底牌**（编剧掌握，按幕释放）：三年前沈峥查到舅舅宋知远借海外港口洗钱，把证据藏进自己的机械表后盖，借口“表慢了”交给林晚去修。当晚在游艇上，宋知远用扳手砸他后脑，推他下海；沈峥挣扎时扯掉一枚船锚袖扣，掌心留下压痕。尸体几天后冲上岸，脸已经认不出，林晚解剖后写“他杀”，周启年收钱改成“意外”，三天内火化。宋知远告诉姐姐儿子是醉酒落水，宋婉仪为保股份让程野顶替，对外说沈峥在海外养病。两年后，替身怕被未婚妻认出来，当众退婚。

## 二、分集铁律

1. 每集林晚至少拿出一样镜头拍得出的证据，可以是新证据，也可以是旧证据的新读法。
2. 沈家每次反扑只用两招：毁证或抹黑；同一招不连用三集。
3. 每集结尾必须留钩子；第 10、22、36、48 集是付费卡点，结尾要有身份级反转。
4. 林晚不抬声调、不哭闹，只靠证据翻盘；爽点只落在沈家人和周启年脸上。
5. 宋知远第 36 集前只能做“可靠的舅舅”，不能让观众提前锁定他是凶手。
6. 三年前的事一律只用闪回碎片呈现：夜、甲板、扳手、手，不拍完整落水。

## 五、人物弧线

- **林晚**：藏着签字的事 → 被逼一步步自曝 → 主动当庭重签。旧表从头戴到尾，只在最后一场摘下。
- **沈砚**：不信 → 当内应 → 害怕凶手是自己 → 被证据洗清，记起是舅舅把他扶回船舱。
- **苏曼丽**：踩人 → 求救 → 反水 → 为自保交出账本，不洗白。
- **程野**：为活命演别人 → 为妹妹倒戈 → 以自己的名字自首。
- **宋婉仪**：护着股份 → 发现亲弟弟杀了儿子 → 交出沈氏。
- **周启年**：拿权压人 → 拿录音保命 → 当庭失势。
- **宋知远**：全剧笑得最和气，直到第 36 集才露出獠牙。

## 六、AI 拍摄约束

- **固定外形锚点**：林晚的齐耳短发、深灰风衣、旧男表；程野的金丝眼镜、白手套；沈砚的寸头、黑耳钉、敞着的西装；苏曼丽的酒红指甲；周启年的金表、胸前老花镜；宋婉仪的旗袍、珍珠耳环；宋知远的船锚袖扣。全剧不换。
- **场景库控制在 8 个以内**：婚礼宴会厅、酒店房间、解剖室/样本室、沈家老宅、游艇甲板（只用于夜间闪回）、修表铺、法庭、墓园。
- **证据都拍特写**：疤、切片、照片、袖扣、表的后盖，一律给手部和物件特写，减少多人同框和大场面。
- **单集控制在 2–3 场**，对白短句为主，每集结尾停在一个证据或一张脸上。
