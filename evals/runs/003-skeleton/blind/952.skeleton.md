# 《验尸官的婚礼》全剧骨架

60集竖屏｜每集1–2分钟｜AI拍摄

## 一、总纲

- **明线问题**：三年前是谁杀了沈峥？
- **暗线问题**：林晚敢不敢推翻自己签过的报告？
- **引擎**：每集一样看得见的证据 → 沈家毁证或抹黑 → 她拿下一样证据反打。离真相越近，离她自己的签名也越近。
- **终点**：法庭上，她重新签下“死者沈峥，他杀”。

## 二、底牌（编剧专用，按第五节放出）

1. 沈峥发现舅舅宋知远借海外港口洗钱，偷录了对话，藏进那块男表的后盖，把表落在林晚家，说“下周来拿”。
2. 一周后，游艇夜。宋知远用扳手砸了沈峥后脑，把人推下海。沈砚醉倒在船舱。沈峥临死攥下宋知远一枚船锚袖扣。
3. 尸体的脸和手被海水泡坏、被鱼啃过，虎口那道疤只剩半截，成了无名男尸，上了林晚的解剖台。同一周“沈峥出国养病”，每天给她发消息（宋知远代发）。她写了“他杀”，周启年收钱逼她改成“意外”，三天火化。周启年私藏了那枚袖扣保命；林晚私留了一张肺组织切片（硅藻阴性，入水前已死）。
4. 宋知远出事前一个月就接触过程野——替身是早就预谋好的，不是事后补救。他骗姐姐“阿峥喝多落水”，劝她找人顶替保股份。
5. 程野不敢靠近未婚妻，拖了两年，一年前当众退婚。
6. 程野的妹妹在宋知远安排的疗养院“治病”，实为人质。

## 三、五幕结构

### 第一幕　婚礼（1–10）：认出替身
- **目标**：让人看见“新郎不是沈峥”。
- **压迫**：沈家和苏曼丽把她打成“闹婚前任”，周启年停她的职。
- **证据**：虎口（换戒指摘手套）→ 宾客视频截图对比订婚照 → 苏曼丽塞的房卡（套房里有整容复诊单和程野妹妹的照片）。
- **黄金三集**：①戒指套上，虎口光洁；闪回解剖台上那半道疤。她站起来：“他不是沈峥。”②保安拖她出去，宋婉仪轻声说：“林小姐病了。”③档案室里，当年的照片已经被换掉。她从风衣内袋摸出那张私留的切片。
- **卡点（10）**：切片DNA和沈砚喝过的酒杯比对，结果“支持同胞兄弟关系”。
- **打谁的脸**：苏曼丽的抹黑视频被截图打脸，沈家公关翻车。

### 第二幕　无名尸（11–22）：证明死者就是沈峥
- **目标**：用DNA逼沈家认账。
- **压迫**：周启年举报她“私留检材”，切片被调走销毁；宋婉仪拿钱和律师压她。
- **证据**：DNA报告（已发进沈砚邮箱，销毁慢了一步）、程野的签名练习本、宋婉仪给整容医院的转账。
- **沈砚线**：从“你图我家的钱”到私下承认“那晚游艇上我也在”（18）。
- **高潮（20–21）**：沈砚当着全家拍出DNA报告。宋婉仪认了替身，但咬定“阿峥是自己掉下去的”。
- **换局（22）**：沈砚翻出当年的鉴定书，签字人：林晚。“你早就知道他是被杀的？”唯一的内应转身走了。
- **打谁的脸**：宋婉仪的体面第一次在儿子面前碎掉。

### 第三幕　游艇（23–36）：谁杀了他
- **目标**：找出凶手。
- **压迫**：宋知远以好舅舅身份帮着查，把嫌疑往程野、沈砚身上引。苏曼丽为港口生意反水，报出游艇位置，游艇被烧。
- **证据**：林晚的手写原始笔记（颅骨凹陷的形状）对上游艇工具箱里的扳手型号；沈砚的记忆碎片（甲板上闪过一道银光）。
- **沈砚线**：他怕凶手是自己。林晚用伤口角度证明凶手比沈峥高、惯用右手，醉酒的沈砚做不到。两人和解（28）。
- **高潮（34–35）**：程野“意外”服药过量，林晚当场判断是投毒，把人抢了回来。
- **换局（36）**：程野开口：“出事前一个月，你舅舅就来找过我。”镜头落在船锚袖扣上，观众确认凶手。

### 第四幕　签字（37–50）：她自己的报告
- **目标**：钉死宋知远，代价是承认自己签过假报告。
- **压迫**：宋知远先动手，把三年前的鉴定书泄给媒体：“女法医当年亲手造假”（38），林晚被立案调查；他拿妹妹要挟，程野改口。
- **证据**：周启年保命用的录音（宋知远打钱的电话）和他从死者手里取走的袖扣。
- **周启年线**：宋知远把受贿全推给周启年，他成了下一个“意外”，来找林晚拿袖扣换保护。林晚的条件：两人一起当众认。
- **苏曼丽线**：她在港口合同里看到自家公司被当成洗钱通道，第二次选边，站到林晚这边。
- **高潮（48–49）**：袖扣摆到宋婉仪面前，和宋知远袖口那只正好配成一对。
- **换局（50）**：宋婉仪知道弟弟杀了儿子、骗了她三年，亲手把沈氏账本交给林晚。

### 第五幕　重新签字（51–60）
- **目标**：把宋知远送上被告席。
- **压迫**：宋知远带着程野的妹妹从港口出逃，洗钱的动机证据也已经转移。
- **证据**：那块表。宋知远三年来一直在找沈峥藏的东西（伏笔：30集公寓被翻，43集他盯着表）。后盖里是沈峥的录音：洗钱对话，最后一句是留给林晚的话。
- **53–54**：沈砚、苏曼丽配合在港口截下船，程野把妹妹换了回来。
- **57–59**：法庭。林晚以原鉴定人身份出庭，撤回自己三年前的结论，写下“死者沈峥，他杀”，签名。宋知远认罪。
- **60**：程野带妹妹去自首；宋婉仪交出沈氏；墓园里，林晚摘下表放在沈峥墓前，手腕上留着一圈白印。

## 六、人物弧

- **林晚**：守着“我签过字”不说 → 当庭推翻自己。不在人前哭，只在22集独自对着表。
- **程野**：怕死 → 为妹妹撒谎 → 自首。**沈砚**：不信 → 内应 → 翻脸 → 和解 → 作证。
- **苏曼丽**：踩她 → 求救 → 反水 → 回头。**周启年**：逼签 → 替罪羊 → 作证。
- **宋婉仪**：护股份 → 护儿子名声 → 交出沈氏。**宋知远**：和气舅舅，36集后也只阴不吼。

## 七、每集铁律

1. 开头3秒接上集最后一个画面，结尾停在新证据或新反咬上。
2. 每集一样能拍特写的证据或反制，拿不出就不成立。
3. 林晚赢靠证据，不靠巧合和别人良心发现。
4. 卡点10／22／36／50，必须换局，不能只留悬念。
5. 不写感情线，林晚和沈砚只是同盟。

## 八、AI拍摄约束

- **只用7个场景**：婚宴厅、解剖室/档案室、沈家客厅、酒店套房、游艇（只拍停泊，落水只拍剪影）、港口仓库、法庭/墓园。
- **外形锁死**：识别件全剧不换——林晚的灰风衣和男表、程野的白手套和金丝眼镜、沈砚的黑耳钉、苏曼丽的酒红指甲、周启年的金表和老花镜、宋婉仪的珍珠旗袍、宋知远的船锚袖扣。
- **沈峥与程野同脸**：区别只在虎口疤、不戴手套、戴那块表。闪回不超过6次。
- **暴力不拍过程**：只拍现场和尸检结果。
- **群戏控制**：开口角色不超过6个，人多用反应镜头切。
