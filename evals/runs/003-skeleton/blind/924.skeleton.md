# 《验尸官的婚礼》全剧骨架

60 集竖屏，每集 1–2 分钟，AI 拍摄。本稿只定全剧怎么走，分集大纲和剧本都以它为准。

## 一、核心

- **核心问题**：三年前是谁杀了沈峥？林晚每往真相走一步，也就离自己签过的那份假报告近一步。
- **主赌注**：林晚的职业和名誉。案子翻过来，签字的她就是共犯。
- **观众契约**：每集林晚都拿出一样看得见的证据，沈家每集都出招毁掉或抹黑；她靠专业赢，不靠别人救。配角能递线索、开门，但每次定输赢的那一下判断由她来做。
- **倒计时**：沈峥三十岁生日那天交割一半股份，在婚礼后一个月。宋家顶替他就是为了熬到这天。
- **时间锚**：三年前游艇夜，沈峥遇害 → 第三天无名尸火化 → 一年前退婚 → 今天婚礼。
- **已定设定**：一年前的退婚是程野顶着沈峥的脸做的，为的是支开最熟悉沈峥的法医。那块旧表是沈峥订婚时送给林晚的，只承担情感，不藏证据。

## 二、四幕走向

**第一幕　婚礼认尸（1–15）**
1 集交换戒指，新郎摘下手套，虎口光洁。闪回：解剖台上那具无名尸，虎口有同一道疤。林晚当众问"疤呢"，被赶出门，苏曼丽泼她一身酒，"疯前任大闹婚礼"的视频冲上热搜。
沈家拿出"激光祛疤记录"。答谢宴上苏曼丽塞给她房卡，放了新郎新婚夜的梦话录音："我不是他……别让我意外。"林晚在灯下看他的手，没有一点疤痕组织，祛疤记录是假的。
**15 集（激励）**：法医中心还留着那具尸体的组织切片，和沈砚扔下的烟头做比对，结果是全同胞。解剖台上躺的就是沈峥，"意外"两个字是她签的。当夜切片被周启年调走。

**第二幕　替身现形（16–30）**
周启年以"违规调档"停她的职，说 DNA 报告是她伪造的；宋婉仪开发布会，说她因爱生恨。沈砚拿一件只有兄弟俩知道的小事去试"哥哥"，对方答不上来，沈砚从此成了内应。
林晚挖出程野：模仿演员，欠着赌债，宋家出钱给他整的容。整容医院半夜失火，档案烧了，她改用牙片：沈峥的旧牙科片和程野的种植牙对不上。
**30 集（中点·转折一）**：交割股东会上她当众放牙片和 DNA，交割冻结，替身在董事会面前露了馅。反转跟着来：宋婉仪私下承认顶替是她安排的，可她一直以为儿子是落水意外。紧接着周启年甩出那份签着"林晚"名字的"意外"报告，舆论一下子翻过去：伪证的人是她。

**第三幕　游艇那夜（31–45）**
她被立案调查。宋知远出面送律师，说"舅舅信你"。她从储物柜里取出三年前的原始初稿，上面是"他杀"，还有周启年红笔改的字，周反咬她伪造。
36 集：照片证实沈砚那夜就在游艇上，却一直瞒着，林晚开始怀疑唯一的内应。40 集：苏家港口的生意离不开宋知远，苏曼丽反水，把初稿交了出去，又作证说林晚骚扰她。林晚在这里落到全剧最低点。
**45 集（3/4·转折二＋大爽点）**：她拿着金表的发票（开票日期在火化后第三天）去找周启年，身上带着录音。周以为她已经完了，说漏嘴："宋知远的钱，你签的字，谁也跑不了。"录音一放，周启年落马。全剧最可靠的舅舅浮出水面。

**第四幕　当庭签名（46–60）**
周启年留着保命用的切片和尸检照片被搜了出来。照片上，死者掌心有一道船锚形压痕，宋知远那对袖扣里有一只是新配的。
宋知远反扑：程野的刹车被人动了手脚，林晚从刹车痕迹看出是人为的，救下了他；宋又扣住程野的妹妹要挟。林晚带沈砚在游艇上复原那一夜，沈砚想起了扳手落下的声音。苏曼丽发现苏家也被拖进洗钱的账里，带着港口账册回头。宋婉仪得知是弟弟杀了自己的儿子，人垮了。
**56–58 集（转折三）**：庭上，宋知远的律师举起林晚当年签的报告："鉴定人自己签的意外。"周启年翻供，说是林晚一个人造的假。林晚当庭推翻自己的报告，认下签字的责任，同时公开那张切片：硅藻阴性，人是死后才入的水。
**59–60 集（结局）**：宋知远认罪，宋婉仪交出沈氏，程野带着妹妹去自首。林晚重写结论"死者沈峥，他杀"，签上自己的名字。不写她受不受处分，这一笔签名就是她的代价，也是她的赎罪。最后一场，墓前放下那块表。

## 四、对手梯队与打脸

苏曼丽与婚礼宾客（1–10）→ 宋婉仪与沈家舆论（16–30、53）→ 周启年（12–45）→ 宋知远（31 集起明面帮忙，45 集起是对手）。

打脸要还的债：程野借沈峥的嘴说她"天天摸死人，晦气"，48 集他只能求她救命；苏曼丽骂她"疯女人"，10 集就得回头求她；周启年说"你签了字就是共犯"，45 集自己栽进去；宋婉仪说她"配不上沈家"，53 集反过来求她查清真相。

## 五、人物弧线

- **林晚**：守着那根刺不说 → 被那份签名反咬 → 当庭亲手推翻自己。
- **沈砚**：不信她 → 成为内应 → 瞒着游艇那夜 → 当庭作证。
- **苏曼丽**：带头踩她 → 偷偷求救 → 为家里生意反水 → 带着账册回头。
- **程野**：替人活着、怕"意外" → 被救 → 带妹妹去自首。
- **宋婉仪**：以为儿子死于意外，只想保住股份 → 知道真相后垮了 → 交出沈氏。

## 七、分集与拍摄守则

- 每集固定走法：3 秒内接上集钩子 → 一个证据道具特写 → 对方出一招 → 集尾钩子。每 5 集左右兑现一次小打脸。
- 人物外形锚点每集一致：林晚的灰风衣和旧表、程野的白手套和金丝眼镜、沈砚的黑耳钉、苏曼丽的酒红指甲、周启年的金表、宋婉仪的旗袍和珍珠、宋知远的船锚袖扣。
- 场景控制在 8 个以内：婚宴厅、答谢宴客房、法医中心解剖室与档案室、沈家老宅、股东会议室、游艇（闪回统一冷蓝调）、法庭、墓园。
- 每场同框不超过 4 人。台词短，靠证据特写和人物反应推进，少用旁白解释。
