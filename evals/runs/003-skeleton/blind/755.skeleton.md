# 《验尸官的婚礼》全剧骨架

60集｜竖屏｜单集1–2分钟｜AI拍摄｜女频·大女主·复仇悬疑

## 一、主线

- **明线**：林晚要证明三件事——新郎是替身；三年前那具无名男尸是沈峥；沈峥死于他杀。
- **暗线**：她每赢一步，就离自己签过的那份“意外”报告更近一步。想赢到最后，她得先认自己的错。
- **对手升级**：沈家（藏替身）→ 周启年（藏报告）→ 宋知远（藏凶手）。
- **谜底**：沈峥发现宋知远借港口洗钱，宋知远在游艇上用扳手砸他后脑，推他下海；之后买通周启年改结论，再让宋婉仪以为儿子是意外落水。

## 二、底层设定（全剧不改）

1. 无名男尸在海里泡了十几天，脸毁了，身上没证件。同一时期沈家对外说沈峥“出国养病”，没人报失踪。
2. 林晚当年的初检结论：后脑凹陷骨折（工具伤，生前伤）、左手虎口旧疤（四年前沈峥替她挡刀留下）、右手两指骨折（生前抓扯）。结论被改后，尸体三天内火化。
3. 林晚私下留了手写初检原稿、一组切片，还有一块蜡块（可提DNA），蜡块用假编号存在中心冷库。
4. 程野顶替后和林晚还保持了两年婚约。他刻意疏远，常戴手套，林晚以为他是病后变了。一年前当众退婚，是怕被法医未婚妻看穿。
5. 林晚手上的机械表是沈峥订婚时给她的，程野从没问过这块表。
6. 遗嘱：长孙沈峥三十岁接手一半股份，人没了就归二房（叔伯一支，不出场，只当背景压力）。
7. 宋知远的船锚袖扣，当晚被扯掉一只，现在戴的是补做的，比另一只亮。
8. 出事后宋婉仪把游艇封在船坞，三年没人动过。
9. 婚礼请柬是苏曼丽发的，为了羞辱林晚。

## 三、五幕结构

**规则**：每集至少有一个证据动作（拿出 / 验证 / 被毁 / 夺回），每次沈家都要反手（毁证或抹黑）；林晚每赢一次，都要提一次那份签字。

### 第一幕 1–10｜婚礼局：当众戳穿
- 入幕：交换戒指时程野摘下手套，左手虎口没有疤。林晚低头看表，站了起来。
- 证据：订婚照上的疤 → 程野认不出那块表 → 婚书签名笔顺不对。
- 反手：宋婉仪拿出“祛疤手术记录”；苏曼丽带头骂她“被退婚的疯女人”；现场视频上了热搜。
- 转折：答谢宴上苏曼丽偷偷塞给她一张房卡，背面写着“他不是他”。
- 出幕（第10集）：林晚翻出三年前无名男尸的档案，照片上左手虎口是同一道疤。签名栏写着：林晚。

### 第二幕 11–24｜身份局：解剖台上的人是谁
- 目标：用蜡块DNA和沈砚做同胞比对。
- 证据：切片证明后脑伤在落水之前，“落水撞礁”的说法站不住 → 蜡块 → 沈砚的样本。
- 反手：周启年以“违规调档”停了她的职；她家起火，手写原稿被烧；网上开始传“女法医纠缠前任”。
- 沈砚：一开始嘲讽她，听她讲出那道疤是怎么来的，才同意交出样本。
- 出幕（第24集）：比对结果是同胞关系。同一天，周启年在全院大会上当众甩出那份“意外”报告：“签字的就是她。”

### 第三幕 25–38｜替身局：撬开程野和周启年
- 证据：房卡→苏曼丽的录音（新婚夜程野打电话：“舅舅，我什么时候能停？”）→ 周启年那块金表的发票和转账记录。
- 苏曼丽反水（第32集）：宋家用港口合约要挟苏家，她把录音原件交了出去，反咬林晚诱供。林晚被举报非法取证。
- 程野动摇：林晚把沈峥的伤情照片摆在他面前：“你是第二个沈峥。”
- 周启年打脸（35–38集）：林晚当众核对金表的来路。宋知远派人灭口（镜头不露是谁），周启年“突发心梗”，林晚当场认出是中毒，把人救了回来。周启年交出当年留的保命录音。
- 出幕（第38集）：录音里给钱的人是宋知远。同一段录音里，周启年说：“小林已经签了，翻不了。”

### 第四幕 39–52｜游艇局：那晚发生了什么
- 宋知远反手：他承认帮姐姐压下“意外”，把找替身的事全推到宋婉仪身上；又放出一段剪过的游艇监控，画面里喝醉的沈砚在和哥哥推搡，嫌疑转到沈砚。
- 沈砚交底：那晚他在船上，什么都记不起来，连他自己都开始怀疑自己。
- 林晚反推凶手：从打击角度看，凶手比死者高，右手持械，从背后下手。船坞工具箱里的扳手和颅骨伤的照片对得上。
- 宋婉仪转向（第46集）：第一次看到儿子后脑的伤，她才知道儿子不是意外死的。
- 程野转向（第49集）：宋知远扣着程野的妹妹。林晚和沈砚把人接出来后，程野交出替身合同和三年来的指令，也承认了退婚的真相。
- 苏曼丽回头（第51集）：宋知远准备甩掉苏家，她交出港口洗钱账本，动机坐实。
- 出幕（第52集）：沈砚在锚链舱的缝里抠出一只船锚袖扣。

### 第五幕 53–60｜法庭局：她签过的字
- 最后一击：辩方当庭质问林晚：“你签过‘意外’，你的话凭什么算数？”她拿出的所有证据都被说成不可信。
- 林晚的选择：当庭承认三年前是被逼改的结论，愿意接受追责，这样初检证据才能重新有效。
- 袖扣上验出沈峥的血迹，袖扣的缺口和死者右手的抓扯伤对得上；宋婉仪出庭作证。宋知远认罪（第58集）。
- 第59集：宋婉仪交出沈氏；程野带着妹妹走进派出所。
- 第60集：林晚重写报告，写下“死者沈峥，他杀”，签上自己的名字。墓园里她摘下手表，放在碑前。最后一个镜头：她空着的左手腕。

## 四、人物弧线

| 人物 | 起点 → 终点 |
|---|---|
| 林晚 | 认证据不认人，只有自己的签字一直躲着不碰 → 把自己也当证据交出去 |
| 沈砚 | 不信她 → 当内应 → 怀疑自己 → 找到袖扣 |
| 苏曼丽 | 踩她 → 向她求救 → 反水 → 为自保回头（不洗白） |

## 六、节奏

- 付费卡点放在第10、24、38、52集，也就是各幕的出幕爆点。
- 每集开头3秒先给证据特写；集尾卡在证据亮出来的前一秒，或者被毁的那一刻。
- 每3集一次小打脸，每幕结尾一次大翻盘。
- 呼吸点：每幕安排一场林晚和沈砚在解剖室外吃夜宵，只聊哥哥。不写感情线。

## 七、AI拍摄约束

- 每个人物锁一件识别物，全剧不换：林晚的表和风衣、程野的手套和金丝眼镜、沈砚的耳钉、苏曼丽的酒红指甲、周启年的金表、宋婉仪的珍珠耳环、宋知远的袖扣。
- 沈峥和程野是同一张脸。沈峥只在闪回里出现，闪回统一用冷蓝调，并露出虎口疤；程野在现时戏里的手部特写一律没有疤。
- 常驻场景最多8个：宴会厅、解剖室、档案室、沈宅客厅、林晚家、船坞游艇、法庭、墓园。
- 动作戏从简：游艇行凶只拍剪影、扳手和落水声；火灾只拍门缝里的烟和烧焦的纸页。
- 所有证据都要设计成能拍近景的物件：疤、切片、录音波形、袖扣、表。

## 八、后续红线

- 第38集之前，不能让观众锁定宋知远是凶手。
- 林晚每次翻盘都要靠专业判断，不能靠运气。别人交出的证据（录音、合同、账本），必须是她先验出破绽、逼对方开口才拿到的，不能白送。
- 苏曼丽只反水一次。
