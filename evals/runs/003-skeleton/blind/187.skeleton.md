# 《验尸官的婚礼》全剧骨架

## 〇 定盘

- **档位**：标准档，60 集，单集 90–120 秒，AI 实拍风，全剧不混档。
- **流派**：主线情绪流，悬疑线调味。悬疑（谁杀了沈峥）只负责往前拉，不抢情绪。
- **情绪契约**：证据摆上台面，谁都得认——最后包括她自己。
- **一句话故事**：被当众退婚的女法医林晚，要让“三年前那具无名男尸＝沈峥，他杀”重新写进结论；挡在前面的是护替身的沈家、逼她签字的周启年，和她自己签过名的那份假报告；她的底牌只有一样：尸体不撒谎，她读得懂。
- **大期待**：第 1 集集尾亮出——“新郎是假的。真的那个，我解剖过。”第 2 集落成具体目标：查出是谁杀了他。
- **逻辑锁**：①当年没认出：尸体面部毁损，沈家说沈峥在国外养病，“他”每周给她打电话——那是模仿演员程野的声音。②一年前退婚：替身最怕的就是未婚妻。③她一眼认出：沈峥虎口有一道替小沈砚挡碎玻璃留下的疤，三年前她把同形的疤画进了无名男尸的体表记录。

## 一 分集铁律

1. **一集一证**：每集林晚必须亮出一样能入画的证据，说不出“本集证物”的集重写。
2. **一证一毁**：对手每次都要毁证或抹黑，毁法不重样：撒谎→抹黑→停职→调包→栽赃→灭口。
3. **双向逼近**：每赢一次，既离凶手近一步，也离她自己的签名近一步，两条都没动＝废集。
4. 林晚靠证据赢，嘴只负责当场戳穿谎话。不扬声调，一句一刀。
5. 集尾断在“证据刚亮一半”，下一集前 15 秒兑现。

## 二 四幕 × 单元链

| 幕 | 集 | 任务 | 单元 |
|---|---|---|---|
| 一幕·入局 | 1–12 | 婚礼点破、被踩、首轮反击 | A 替身局 1–20 |
| 二幕·纠缠 | 13–34 | 替身闭环→翻自己的案 | B 签字局 21–42 |
| 三幕·风暴 | 35–49 | 揪出周启年，凶手反咬盟友 | C 凶手局 43–60 |
| 四幕·封神 | 50–60 | 袖扣、录音、重审 | |

单元换对手不换情绪，主证物一路升级：**疤 → 切片 → 录音**。

### 单元 A 替身局（1–20）｜被动自证

执念：全家咬定新郎就是沈峥，林晚是被甩后发了疯。对手：宋婉仪、苏曼丽、程野。

- **回合 1（1–3）虎口**：交换戒指时白手套滑落，虎口光洁。宋婉仪说激光祛了疤，苏曼丽带头泼酒，保安把林晚架出去。断：答谢宴上苏曼丽塞来一张房卡。
- **回合 2（4–7）指纹**：房卡背面写着“他不是他”。新郎酒杯上的指纹和沈峥留在她家的旧钢笔对不上；一年前的退婚也想通了。反击：热搜“女法医婚闹”，周启年停她职。
- **回合 3（8–11）耳后疤**：停车场堵住程野，抹开他耳后的遮瑕，整容切口露出来。程野发抖：“我妹妹在他们手里。”**一级墙（10）**：他刚说出“你哥三年前——”，宋知远推门进来，笑着替林晚解围。
- **回合 4（12–15）沈砚**：沈砚不信她，林晚说出虎口疤的来历——沈峥只跟她和沈砚讲过。沈砚倒戈成内应。反击：宋婉仪伪造“国外车祸修复”病历，整容疤变得合理。
- **回合 5（16–20）DNA·闭环**：沈氏周年宴上，沈砚当众抽血做兄弟比对，排除亲缘，程野摘下手套。宋婉仪认下替身，却咬死：“我儿子是落水，意外！”
- **火种**：林晚问落水是哪一天。就是那一天，无名男尸上了她的解剖台，结论“意外”，签名：林晚。

### 单元 B 签字局（21–42）｜主动设局

执念：“意外溺亡、已火化”的官方结论翻不了；要翻，先翻她自己。对手：周启年，A 对手背后替沈家收尾的人。

- **回合 1（21–24）档案**：**二级墙（23）**：她打开当年的档案袋，原始记录写着“他杀”，被人划掉。周启年站在她身后：“翻吧，第一个进去的是你。”
- **回合 2（25–28）切片**：她违令私留的一盒组织蜡块，和沈砚比对——是沈峥。反击：周启年举报她私藏检材，蜡块被收缴、调包。
- **回合 3（29–32）颅骨片**：从留档 X 光片看，后脑凹陷是扳手类钝器打的，不是礁石撞的。反击：片子被说成伪造，她被内部审查。
- **回合 4（33–36）攻守转换**：林晚当众签认错书假装认输；周启年连夜去销毁最后一份原件，被沈砚拍下。
- **回合 5（37–40）金表·闭环**：调查会上，林晚念出周启年那块金表的购买方——宋知远名下的海外公司。周启年认下收钱改结论。
- **火种 + 至暗（41–42）**：宋知远“大义灭亲”：“钱是我给的，我是在保沈砚。”拿出沈砚那晚在游艇上和哥哥争吵的照片；苏曼丽为了港口合同作证（她唯一一次反水）；沈砚自己也记不清。林晚被立案。**三级墙（42）**：沈砚被带走前回头：“是不是我？”

### 单元 C 凶手局（43–60）｜掌控规则

执念：宋知远是全家最可靠的舅舅，凶手是沈砚。对手：宋知远。

- **回合 1（43–46）创口角度**：骨折角度推出凶手是高个、右手、自上而下打的——对不上沈砚。反击：宋知远说她为情人翻案。
- **回合 2（47–50）袖扣**：周启年为求减刑，交出当年留的保命符：尸体手心攥着的一枚船锚袖扣。反击：沈家男人人手一对。沈砚掏出他那对，完整；宋知远袖口那对，有一枚颜色新。
- **回合 3（51–54）录音**：沈砚想起那晚开着手机。泡过海水的旧手机被修复，录到了争吵、一声闷响、宋知远的声音。反击：宋知远扣住程野妹妹逼他顶罪；程野反水，交出替“沈峥”签过的海外洗钱文件。
- **决战（55–58）**：重审庭上，林晚当庭推翻自己三年前的报告。宋知远认罪；宋婉仪得知是弟弟杀了儿子，交出沈氏；程野带妹妹自首；苏曼丽交出港口账。
- **尾声（59–60）**：林晚领下处分，重新写下“死者沈峥，他杀”，签上名字。墓前，她摘下那块表放好。

## 三 情绪点与钩子网

- **大情绪点**：1 婚礼点破 / 7 退婚真相 / 12 沈砚倒戈 / 20 替身落地 / 28 切片认亲 / 36 抓现行 / 40 周启年认罪 / 46 洗清沈砚 / 53 录音 / 58 当庭改报告 / 60 墓前。
- **信息差**：A 林晚与观众知道新郎是假的，沈家只当她疯；B 签名是她自己的，刀在周启年手里；C 观众比林晚早看见宋知远袖口（第 10 集特写起埋），等她追上来。
- **游艇闪回**：同一组固定镜头，每单元多给一格（A 落水背影 / B 后脑一声闷响 / C 握扳手的手 + 袖扣）。只能由证物触发，禁旁白讲设定。

## 四 人物弧光

- 林晚：认证据不认人 → 发现最该认的证据是自己的签名 → 当庭认。
- 沈砚：不信 → 内应 → 嫌疑人 → 用自己的手机救自己。
- 苏曼丽：踩人 → 求救 → 反水 → 赎罪。
- 程野：怕死 → 动摇 → 被逼顶罪 → 自首。
- 周启年：A 停她职 → B 正面对手 → C 污点证人。
- 宋婉仪：护替身 → 认替身 → 知真相交权。
- 宋知远：第 10 集以好人登场，第 41 集才翻面，此前不许露凶相。

## 五 AI 制作与合规

- **主景 ≤8**：解剖室、沈宅客厅、宴会厅、酒店走廊、停车场、周启年办公室、法庭、墓园；游艇只拍闪回。宴会只拍前景几人，背景虚化，不上大群演。
- **人物锚点**（AI 一致性）：林晚灰风衣 + 男表；程野金丝眼镜 + 白手套；沈砚黑耳钉 + 敞扣西装；苏曼丽酒红指甲；周启年老花镜 + 金表；宋婉仪旗袍珍珠；宋知远船锚袖扣。
- **尺度**：尸体只拍白布轮廓、X 光片、显微切片，不露创口；击打用闷响加黑屏。
- **公职形象**：机构用虚构名；腐败只落在周启年个人身上，依法处理；警方、法庭正面呈现，程序正当。
