# 《验尸官的婚礼》全剧骨架

60 集｜竖屏｜单集 1–2 分钟｜AI 拍摄
用途：管分集大纲和剧本。

## 一、全剧主轴

林晚每集拿出一件看得见的证据，打穿沈家和周启年；每赢一次，离"谁杀了沈峥"更近，也离她签的那份"意外"更近。最后一件证据是她自己的签名。

- 主问题：三年前谁杀了沈峥？
- 代价线：真相成立，就等于她当年签的是假报告。
- 嫌疑走向：宋婉仪（1–30）→ 沈砚（31–36）→ 宋知远（37 起）。
- 证据阶梯：疤 → 签名练习纸 → 蜡块 DNA → 指纹 → 录音 → 颅骨照片 → 金表 → 血迹与袖扣 → 存储卡 → 她的签名。

## 二、底牌（编剧组内部，不得改动）

1. 四年前，林晚与沈峥订婚。沈峥左手虎口有一道七针的疤，是她亲手缝的。
2. 三年前游艇上，沈峥质问宋知远借港口洗钱。宋知远用扳手砸他后脑，推下海；沈峥挣扎时扯掉一枚船锚袖扣，卡进甲板缝。沈砚醉倒在船舱，醒来手上有血，什么都不记得。
3. 出事前一天，沈峥把旧机械表交给林晚："帮我收着。"表后盖里藏着洗钱账目的存储卡，她至今不知。
4. 宋婉仪只知儿子"落水失踪"。为保住长孙三十岁继承的股份，宋知远替她找来程野整容顶替，对外说"在国外养病"，数月后回国。
5. 尸体数日后捞起，面部损毁，按无名尸送检。林晚主检：颅骨凹陷骨折，生前伤，初稿写"他杀"。她看见虎口的疤，当晚打给沈峥，接电话的是程野学的声音："我在瑞士，挺好的。"她信了。
6. 周启年收了宋知远的钱和金表，逼她改成"意外·礁石撞击"，三天火化。她签了字，私留一块组织蜡块和手写初检笔记。
7. "沈峥"回国后推说病后洁癖，手套从不摘，对林晚冷淡；她以为是病，又困在签字的愧疚里。一年前宋知远怕她看穿，让他当众退婚。婚礼交换戒指，是她三年来第一次看见他的左手。
8. 第 22 集给程野投毒的是宋知远，第 37 集前林晚和观众都以为是宋婉仪。

## 三、四段结构

### 第一段 婚礼验尸（1–10）

- 段目标：证明那具无名尸是沈家人。
- 主压迫：沈家当众羞辱，周启年停职。
- 关键拍
  - 1：苏曼丽寄请柬羞辱她。交换戒指时新郎摘下白手套，虎口光洁。闪回解剖台上那道七针疤。林晚起身："新郎不是沈峥。"
  - 2–3：宋婉仪轻声一句"林法医伤心过度"，保安架她出去；"沈峥"说疤去年做了祛疤。周启年在宾客席，次日停了她的职。宋知远递来纸巾，袖扣给特写。
  - 4–6：答谢宴上苏曼丽泼她一身酒，转身塞给她房卡。婚房里搜出一整页"沈峥"签名练习纸。沈家放出"前未婚妻闯婚房"视频，网暴开始。
  - 7–9：周启年下令销毁旧蜡块，她藏的那块躲过一劫。她去取沈砚的 DNA，被当场抓住。沈砚抽了管血拍在桌上："验出来不是，你就滚出这座城。"
  - 10【卡点】：同胞关系成立。沈砚第一次没笑。周启年打来电话："签'意外'的，是你。"
- 段末换局：林晚有了内应，也第一次被自己的签名威胁。

### 第二段 剥替身（11–30）

- 段目标：让"沈峥"当众现形，逼出找替身的人。
- 主压迫：宋婉仪，加倒计时：第 28 集"沈峥"满三十岁，签字接股份。
- 关键拍
  - 11–13：周启年宣布私检 DNA 违规，结果作废。宋婉仪放出伪造的林晚精神科就诊记录。
  - 14–17：林晚想通白手套是防指纹的。酒会上苏曼丽"失手"泼酒，逼他摘手套。酒杯指纹和沈峥旧书上的对不上。
  - 18–21：沈砚翻出程野当年的夜场模仿秀视频。林晚找到程野的妹妹程雨，透析费由沈氏账户代付。程野堵她："别碰她。"林晚："哪天你没用了，她的透析费也会停。"
  - 22–25：程野"醉酒"倒在车里，林晚看瞳孔断定是投毒，把人救回。程野交出保命录音，是宋婉仪的声音："从今天起你就是沈峥。他是自己掉下去的。"
  - 26–28：交接仪式上，林晚带着录音、指纹和程野本人进场。程野当众摘下手套和眼镜，宋婉仪现形。
  - 29–30【卡点】：宋婉仪认了："替身是我找的，可我儿子是落水。"同时周启年把她签字的旧报告发给媒体，热搜：法医收钱改结论。
- 段末换局：替身线收官，命案线开启，林晚从揭发者变成被告。

### 第三段 从意外到他杀（31–45）

- 段目标：推翻"意外"，找到凶手。
- 主压迫：立案调查、舆论、周启年。宋知远以"公道舅舅"身份暗中带偏。
- 关键拍
  - 31–33：林晚被立案。宋知远私下递来"宋婉仪给周启年转账"的单据，把锅推给姐姐。
  - 34–36：沈砚坦白那晚他在船上，醒来手上有血。林晚用初检照片还原：颅骨凹陷是扳手的半月形，打击角度推出凶手身高 185 以上、右手持械。沈砚 175，洗清。
  - 37–40：金表编号查到宋知远名下的海外公司，那张单据是假的。周启年在法医中心当众被带走，矛头第一次指向宋知远。
  - 41–42：宋知远要拆卖游艇。林晚、沈砚、苏曼丽夜上游艇，鲁米诺喷过甲板，三年前的血迹泛出蓝光；甲板缝里撬出那枚船锚袖扣。
  - 43–45【卡点】：苏曼丽反水：宋知远捏着苏家的港口许可。她扣下袖扣当苏家的筹码，还作证林晚"栽赃"。林晚被拘。宋知远来探视，袖扣一新一旧："你签过一次，就能签第二次。"
- 段末换局：凶手清楚了，证据全丢，林晚失去自由。

### 第四段 她自己的签名（46–60）

- 段目标：让宋知远认罪，并亲手推翻自己的报告。
- 主压迫：宋知远出境倒计时，和她的签名。
- 关键拍
  - 46–48：沈砚交出夜上游艇的全程视频，证明袖扣是当场撬出的，林晚取保。沈砚想起哥哥那晚的话："东西我放在晚晚那儿了。"她撬开表后盖，存储卡里是洗钱账目，和沈峥的一段语音："如果我出事，去问舅舅。"
  - 49–51：账目里也有苏家港口。林晚找苏曼丽："拿着它，苏家陪葬；交出来，苏家是证人。"袖扣交回。宋婉仪听完儿子的语音，交出弟弟当年安排替身的转账和那条"就说是意外"的短信，转做证人。
  - 52–54：宋知远要从港口出境，约林晚上游艇"谈条件"。这是林晚设的局，录音全程开着。他举起扳手，船舱里走出戴金丝眼镜的"沈峥"，是程野最后一次扮他。宋知远愣住，警灯亮起。
  - 55–58：庭审。辩方举起她签的"意外"："这是鉴定人自己的结论。"林晚当庭："这份是我签的，是假的。"她撤回原报告，接受追责，写下"死者沈峥，他杀"，签上名字。周启年认收钱，宋知远认罪。
  - 59：宋婉仪交出沈氏，程野带着妹妹去自首。苏家被查。
  - 60：墓园。林晚把表放在沈峥墓前。

## 四、管分集与剧本的硬规则

1. 每集必须亮出一件证据，或一件证据被毁、被抹黑。不准空集。
2. 集尾停在变化上（证据露头、被毁、身份被戳穿、局面反转），不停在情绪上。
3. 林晚不抬声调，不哭诉。赢的那一下 = 证据特写 + 一句短话，嘴可以毒。
4. 爽点只落在沈家（含苏曼丽）和周启年。宋知远第 37 集前不输，每次出场都在"帮忙"，并带一个伏笔：袖扣、身高、港口三选一。
5. 签名代价线每段至少响一次：第 10、30、45、57 集。
6. 三年前的戏只用一组冷色闪回（解剖台、游艇甲板、那通电话），镜头复用，每次多露一点。
7. 信息差以第二节为准。分集大纲每集标明：谁新知道了什么。

## 五、AI 拍摄约束

- 主场景不超过 8 个：婚礼宴会厅、婚房、法医中心（解剖室和主任办公室）、沈家客厅、医院、游艇、法庭、墓园。
- 造型全剧锁死：林晚灰风衣、旧表；程野金丝眼镜、白手套；沈砚敞扣西装、黑耳钉；苏曼丽酒红指甲；周启年金表、胸前老花镜；宋婉仪旗袍、珍珠；宋知远船锚袖扣。
- 每集说话角色不超过 3 个，2–3 场戏。
- 不拍水下、追车、群架；落水、投毒、扳手只拍前后一秒。
- 证据一律给竖屏特写，不听台词也看得懂。
