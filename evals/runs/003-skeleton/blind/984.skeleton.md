# 《验尸官的婚礼》全剧骨架

60集｜竖屏｜每集1–2分钟｜AI制作｜女频·大女主·复仇悬疑·豪门

分集大纲和剧本都要服从本稿。标【新设】的是选题卡没写、本稿补的设定，其余沿用选题卡。

## 一、全剧发动机

- **真钩子①**：三年前是谁杀了沈峥？
- **真钩子②**：林晚什么时候亲手推翻自己签的那份报告？
- **回合机制**：林晚亮出一件看得见的证据 → 沈家毁证据、抹黑她 → 她靠专业翻盘 → 离凶手近一步，也离自己的签名近一步。每次赢都要付代价（停职、违规曝光、被拘），不能白赢。
- **证据阶梯**：疤 → 切片 → 照片 → 录音 → 袖扣。逐级加码，同一种证据不重复用来翻盘。

## 二、前史

- 四年前：林晚和沈峥订婚，沈峥把戴了多年的旧机械表给了她【新设】。
- 三年前：沈峥查出舅舅宋知远借港口洗钱，在游艇上被扳手砸中后脑、推下海。挣扎时他扯下一枚船锚袖扣攥在手里。沈砚醉在船舱。宋知远跟姐姐说是失足落水。
- 半个月后，一具面部损毁的无名男尸上岸。周启年接收时独自取走了那枚袖扣，留着要挟宋知远【新设】。林晚解剖，原稿写的是“后脑凹陷性骨折，他杀；左手虎口陈旧疤；右掌心圆形压痕”。周启年收了钱，改成“意外”，逼她签字，三天内火化。沈家对外说沈峥出国养病，所以她没想到死者是他。她私下留了一张切片【新设】，这是她的第二根刺。
- 宋婉仪为了保住股份，找来程野整容顶替。程野的妹妹由宋知远“安排治疗”，这是拴住他的绳子【新设】。
- 同年，“沈峥”养病回国，和林晚的婚约又维持了两年。他一直戴手套，说是落水伤了手，人也冷了。林晚以为是后遗症，从没见过他的光手【新设】。一年前，为了跟苏家联姻、也为了甩开这个法医，他当众退婚。

## 三、知情边界（锁定，不得提前）

| 信息 | 观众 | 林晚 |
|---|---|---|
| 新郎是替身 | 第1集 | 第1集 |
| 周启年背后另有人 | 第10集（只给声音或背影） | 第30集 |
| 沈砚当晚在游艇上 | 第22集（噩梦闪回） | 第42集 |
| 凶手是宋知远 | 第30集 | 第40集 |
| 宋婉仪不知道是谋杀 | 第35集 | 第49集 |

第30集之前，掌心压痕和宋知远的袖扣不能出现在同一画面，也不能剪在一起。

## 四、五段走向

### 第一段 1–10｜疤：新郎是假的

- 苏曼丽特意发请柬让林晚来看婚礼，林晚来还订婚戒指。交换戒指时程野摘下手套，虎口光洁。林晚闪回到解剖台上的那道疤，当场抓住他的手。
- 沈家出招：宋婉仪拿出“祛疤病历”，苏曼丽带头骂她嫉妒发疯，视频上了热搜，周启年停了她的职。
- 林晚翻盘：她拿那块表试他（只有沈峥知道表为什么慢七分钟【新设】），程野答错。答谢宴上，苏曼丽当众泼她酒，同时塞给她求救的房卡。房间里是苏曼丽偷拍的新婚夜：丈夫对着镜子练沈峥的签名。
- **第10集一卡卡点**：林晚去档案室调三年前的卷宗。原稿没了，只剩一页“意外”，签名是她自己。周启年站在门口：“要查，第一个查的是你。”末镜是一个男人背对镜头挂断电话：“问问她，当年留了东西没有。”

### 第二段 11–20｜切片：死者是沈峥

- 私留的切片是唯一能做DNA的东西，但比对需要沈家血亲。她去找最不信她的沈砚。沈砚先羞辱她，再试她，最后拿出自己的头发，因为他也想知道哥哥到底是谁。
- 沈家出招：实验室起火，样本被调包；她“私藏人体组织”被曝光，面临吊销资格。离真相越近，她自己的违规也越藏不住。
- 林晚翻盘：她早就把切片一分为二，另一半寄存在外地鉴定所。**第20集**，沈砚带她进沈氏股东会，她当众公布结果：亲缘关系成立，死者是沈峥。替身被当众揭穿，程野被宋家藏了起来。

### 第三段 21–30｜照片：不是意外

- 宋婉仪认下顶替，但咬死“落水意外，法医结论在这儿，签字的是林晚”。战场从“他是谁”转到“他怎么死的”。
- 沈砚成了沈家内应，第22集起常梦到游艇。林晚找到当年被逼删照片的摄影技师，拿回原始照片：后脑凹陷骨折，掌心圆形压痕。
- 沈家出招：技师翻供，照片被说成伪造，林晚被告“为报复前任家族伪造证据”。
- 林晚翻盘：一张原始底片拍进了周启年划掉“他杀”的手，腕上是那块金表【新设】，经鉴定为真。
- **第30集中点**：周启年被当众带走（爽点）。反转：审讯中他把事情推给林晚和宋婉仪，说钱“是沈夫人给的”。集尾，宋知远探视周启年，指尖碰了碰袖扣：“那枚扣子，还在你手里吧？”

### 第四段 31–40｜录音：至暗

- 宋婉仪被当成杀子嫌疑人，反扑得最狠，她以为是林晚在毁她的家。宋知远以“最可靠的舅舅”的身份帮林晚、护姐姐，两头递刀。观众知道、林晚不知道，张力就在这里。
- 宋知远要程野“意外”（连车坠海，复刻沈峥的死法）。林晚和沈砚救下他。程野交出保命录音：顶替那夜宋婉仪的交代，背景里宋知远在劝姐姐“就当是落水”。这证明宋婉仪只管了顶替。可妹妹还在宋知远手里，程野不敢出庭。
- 苏曼丽反水：宋知远威胁让苏家替港口洗钱背锅，她把林晚的证据副本交了出去，还作证说林晚骚扰她。
- **第40集至暗**：林晚被刑拘，证据全毁，沈砚被赶出沈家，程野失踪。宋知远来看守所探望，替她请了律师，抬手整理袖口：两枚船锚袖扣，一新一旧。林晚盯着那枚新的，想起了掌心的圆印。

### 第五段 41–60｜袖扣：凶手和那份报告

- **41–45**：沈砚终于说出游艇那晚他也在船上，只记得哥哥和舅舅在吵“港口的账”（只当动机，不当证据）。他把林晚保了出来。周启年在羁押医院“自杀”，林晚一眼看出是勒杀未遂，救下老领导。他求她，交出了那枚袖扣和宋知远给他打款的录音。
- **46–50**：苏曼丽发现苏家还是被定成替罪羊，带着港口资金流水回来。袖扣上验出沈峥的血和宋知远的DNA。第49集，林晚把颅骨照片和袖扣放到宋婉仪面前，宋婉仪第一次知道儿子是被亲弟弟砸死的。**第50集卡点**：宋知远带着程野的妹妹上了当年那艘游艇。
- **51–54**：程野拿自己去换妹妹，宋婉仪亲自上船拖住弟弟，宋知远落网。
- **55–60**：庭审。辩方的最后一张牌是：全案唯一的法医结论是“意外”，签字人林晚。她当庭推翻自己三年前的报告，承认被逼签字、私留切片，接受处分。法庭委托重新鉴定，她写下“死者沈峥，他杀”，签上自己的名字。宋知远认罪伏法，宋婉仪交出沈氏，程野带妹妹自首。最后一场，林晚把那块表放在沈峥墓前。

| 程野 | 前期帮沈家压林晚；第35集交录音；第52集拿自己换妹妹 | 从替人活着，到为自己做一次选择 |
| 沈砚 | 第15集给头发；第42集说出游艇那晚 | 从不信她到唯一的内应，也承认自己没护住哥哥 |

## 六、分集与剧本必守

1. 每集至少一件能拍的证据物或证据动作（疤、表、切片、照片、录音、袖扣、签名）。集尾钩子落在证据上，下集30秒内回应。
2. 沈家每次反扑要换方式：造假 → 毁证 → 舆论 → 法律 → 灭口。不准换个地点重复同一场争吵。
