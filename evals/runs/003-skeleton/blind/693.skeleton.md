# 《验尸官的婚礼》全剧骨架

> 60 集｜竖屏｜每集 1–2 分钟｜AI 仿真人｜女频复仇悬疑。只管全剧走向，后续分集大纲与剧本必须服从本文件。

## 一、全剧契约

- **明线问题**：三年前是谁杀了沈峥？
- **暗线问题**：林晚敢不敢推翻自己签过的那份报告？
- **观众承诺**：每集她拿出一件看得见的证据，沈家每集都想毁掉它、抹黑她；她每赢一次，离真凶和她自己的签名都更近一步。
- **为什么不能一次掀牌**：①没有尸体，只有当年的记忆和私留的样本；②指认替身，就等于承认那具无名尸是沈峥，而“意外”是她签的字；③沈家握着舆论、股份和法医中心的人。
- **终点变化**：从“我是被逼的，那个签名不算我的”，到“签名是我的，我来改”。

## 二、底层真相（编剧专用，不得提前泄露）

- 沈峥发现宋知远借海外港口洗钱，游艇上被扳手砸中后脑，推进海里。沈砚醉倒在船舱。
- 七天后尸体漂上岸，面部损毁、没有证件。林晚解剖时写了“他杀”，周启年收钱改成“意外”，逼她签字，三天火化。她没认出死者：沈家对外说沈峥“出国养病”，那段时间程野还模仿他的声音给她打过电话。
- 她违规把一块颅骨伤口的蜡块和切片藏在别的档案编号下，这是她唯一的违规，也是全剧底牌。
- 旧机械表是沈峥上游艇前摘给她的：“回来给你换块新的。”替身退婚时从没提过这块表。
- 宋婉仪以为儿子是落水意外，为保长孙股份找了程野顶替，不知道凶手是弟弟。

## 三、三件主证据

| 主证据 | 主管集数 | 证明什么 | 沈家怎么毁 |
|---|---|---|---|
| 一道疤（左手虎口） | 1–20 | 新郎不是沈峥 | 白手套、补画假疤、说她是纠缠前任的疯子 |
| 一张切片（颅骨伤口＋金属微粒） | 13–40 | 无名尸是沈峥，而且是他杀 | 抢档案、烧样本、曝光她的伪证，让证据失效 |
| 一段录音（周启年的保命录音） | 41–60 | 宋知远买通周启年改结论 | 对周启年灭口、扣下程野的妹妹、收买苏曼丽 |

**规则**：每集至少一件小证据（指纹、表痕、签名笔压、监控、船检记录……），必须拍得成特写；证据被毁要留下新线索，不能白丢；同一种毁证手段最多用两次。

## 四、四条阶梯

**揭露**：R0 新郎虎口没有疤 → R1 新郎是模仿演员程野，宋婉仪知情 → R2 DNA 证实无名尸是沈峥，她解剖的是自己的未婚夫 → R3 凶器是扳手，案发在游艇上，沈砚当时在船上 → R4 凶手是宋知远（船锚袖扣少了一只）→ R5 动机是港口洗钱，苏家的生意也沾了脏钱。

**对手**：E1 苏曼丽和婚礼宾客（当众羞辱）→ E2 周启年（停职、毁档，手里有她的签名）→ E3 宋婉仪和沈家（舆论、律师、股份）→ E4 宋知远（看懂她的打法，转去攻击她的信誉和证人）。**镜像**：宋知远和林晚都把“他杀”变成过“意外”，一个为了钱，一个因为怕。

**能力**：看出破绽 → 拿一件证据赢一局 → 主动设局，让沈家自己毁证时露馅 → 护住证人 → 当庭交出自己。

**代价**：停职 → 沈砚得知她签过“意外”，翻脸 → 伪证曝光，被吊销执业资格 → 人身危险 → 当庭自认，赌上职业生涯。

## 五、七段走向

| 段 | 集 | 本段问题 | 关上的门 → 打开的门 |
|---|---|---|---|
| 一 婚礼 | 1–5 | 新郎是谁？ | 借敬酒逼新郎摘下手套，虎口光洁；答谢宴上苏曼丽偷偷塞来房卡 → 新娘也在害怕 |
| 二 替身 | 6–12 | 怎么证明他不是沈峥？ | 苏曼丽交出新郎新婚夜留下的指纹，和沈峥旧档案里的指纹对不上；她被抹黑成“疯前任”、被周启年停职，查出程野的真实身份 → 宋婉仪知情 |
| 三 切片 | 13–20 | 无名尸是谁？ | 周启年要销毁旧档，她抢出切片；沈砚从不信她到交出 DNA；第 20 集比对结果：沈峥 → 报告是她签的 |
| 四 母亲 | 21–30 | 谁在撒谎？ | 沈砚翻脸后又回来；宋婉仪坚持说是意外，宋知远以“可靠舅舅”的身份出面调停。**第 30 集错胜**：她当众揭穿替身，沈家大乱、股份冻结；同一集宋知远放出她签字的伪证 → 猎人变猎物 |
| 五 游艇 | 31–40 | 那晚船上发生了什么？ | 没了执照，只能靠切片和现场重建；宋知远栽赃沈砚，她用伤口角度推出凶手的身高和惯用手，洗清沈砚；程野想反水，苏曼丽为了家里的生意向宋知远告密，程野的妹妹被扣，程野翻供 → **全剧最低点** |
| 六 录音 | 41–50 | 谁买通了周启年？ | 宋知远制造周启年“意外”，林晚救下他，拿到录音；宋婉仪听见弟弟的声音，第一次站到林晚这边；宋知远牺牲苏家港口自保，苏曼丽再次倒戈；救出程野的妹妹 → 法庭前只剩她自己的签名 |
| 七 当庭 | 51–60 | 她敢不敢推翻自己？ | 宋知远最后一招：以“伪证法医”否定全部证据；她当庭承认三年前的签字，重写“死者沈峥，他杀”并签名；宋知远认罪伏法，宋婉仪交出沈氏，程野带妹妹去自首；墓前放表 |

## 六、人物弧

- **林晚**：想要的是证明新郎是假的，真正需要的是承认签名是自己的。她的“弱”只能来自没执照、没尸体、身上有污点，不能靠降智。情感核心是对沈峥的愧疚和思念，不另开恋爱线。
- **沈砚**：纨绔 → 怀疑凶手就是自己（那晚的记忆是空白）→ 内应 → 接住哥哥留下的东西。“那晚我在船上”这句话到第五段才说出口。
- **程野**：替别人活 → 为了妹妹出卖自己 → 选回自己的名字。他不知道沈峥怎么死的，只能交代替身是怎么来的。
- **苏曼丽**：带头踩人 → 求救 → 反水 → 还债。两次转向都要有生意账作理由。
- **宋婉仪**：想保股份的母亲，不是凶手。她的转向只能由证据（录音）触发，不能靠哭戏。
- **周启年**：守门人 → 弃子 → 证人。留录音是为了自保，不是出于良心。
- **宋知远**：一直温和，从不亲自出手；每输一局就换一种打法（毁物 → 毁人 → 毁信誉），第五段之后才露出狠。

## 八、伏笔

- 白手套（1）→ 摘下（3）→ 补画假疤，被她看出愈合期不对（11）
- 旧表（1）→ 替身不认得这块表（6）→ 无名尸左腕表痕的宽度和表带一致（18）→ 墓前（60）
- 船锚袖扣（1，宋知远整理袖口）→ 一对成色不同（24）→ 沈砚记忆里的“银船锚”（35）→ 法庭（57）
- 程野的妹妹（8，提到医药费）→ 被扣（40）→ 一起自首（60）

## 九、AI 连续性锁

- **识别物不可漂移**：林晚的灰风衣＋男表；程野的金丝眼镜＋白手套（虎口是关键特写）；沈砚的右耳黑耳钉＋不扣扣子的西装；苏曼丽的酒红指甲；周启年的金表＋胸前老花镜；宋婉仪的旗袍＋珍珠耳环；宋知远的船锚袖扣。
- **主场景**：婚礼厅、解剖室、档案室、沈家老宅、游艇、法庭、墓园。三年前的戏一律用同一套冷色回忆调。
- **每集底线**：一个证据特写，加一次权力或信息的变化；不靠旁白念剧情。
