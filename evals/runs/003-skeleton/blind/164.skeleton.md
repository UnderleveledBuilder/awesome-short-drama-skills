# 《验尸官的婚礼》全剧骨架

60集｜竖屏｜每集1–2分钟｜AI拍摄｜女频·大女主·复仇·悬疑·豪门

## 一、总控

- **主线问题**：三年前是谁杀了沈峥？
- **暗线问题**：林晚自己签下的那份"意外"报告，她敢不敢推翻？
- **推进方式**：她每赢一局，离凶手近一步，也离自己的签名近一步。两条线在法庭上同时到站。
- **终点画面**：林晚当庭写下"死者沈峥，他杀"，签上自己的名字。

## 二、铁律（分集大纲必须遵守）

1. 每集出一样能拍特写的证据（实物或声音），不拿推理台词顶替。
2. 每集沈家或周启年反扑一次（毁证、抹黑、施压），手段按段升级。
3. 林晚不抬声调，爽感来自证据落地，不靠吼。
4. 爽点只落在沈家一家和周启年脸上；程野、沈砚、苏曼丽可以吃瘪，但不是最终仇人。
5. 集集留尾钩；每段最后一集必须是大反转。

## 三、逻辑底座（时间线）

- **四年前**：林晚与沈峥订婚，沈峥把自己的旧机械表给了她。沈峥左手虎口有一道旧疤。
- **三年前**：沈峥发现宋知远借海外港口洗钱。游艇上，宋知远用扳手砸他后脑，推下海；沈砚醉倒在船舱。
- **数日后**：一具面部被海水泡毁的无名男尸上了林晚的解剖台。她记下"虎口陈旧疤痕""后脑钝器伤"，结论写"他杀"；周启年收了宋知远的钱，改成"意外"逼她签字，三天火化。她私下留了一张颅骨切片和一张死者掌心照片，掌心有一道船锚形压痕。
- **同期**：宋婉仪以为儿子落水，为保股份让弟弟找来程野整容顶替。"沈峥"对外说从国外养病回来，对林晚刻意疏远。
- **一年前**：程野怕被林晚近距离认出，当众退婚，骂她晦气。
- **计时器**：沈峥三十岁生日当天股权交割（第50集）。交割完成，程野就没用了。

## 四、人物弧线

- **林晚**：守着一根刺不说 → 当庭把它拔出来。缺陷是只认证据不认人，嘴上不饶人，会把盟友推开。
- **程野**：替身木偶 → 活证人。软肋是妹妹，被宋知远捏在手里。
- **沈砚**：不信她 → 唯一内应。游艇那晚的记忆空白是他的心魔，也是最后一块拼图。
- **苏曼丽**：踩她 → 暗中求救 → 为生意反水 → 最后站回来。
- **周启年**：体面的老领导 → 被扒出收钱 → 想拉林晚陪葬。
- **宋婉仪**：护股份的母亲 → 得知儿子是被杀 → 交出沈氏。
- **宋知远**：全剧最可靠的舅舅 → 最后的对手。第1集起就在画面里，只是没人看他。

## 五、五段结构

**第一段 婚礼识破（1–8）**
林晚被当成来闹婚礼的前任。交换戒指时新郎摘下左手手套，虎口光洁。她试探他认不认得那块表，他认不出；婚书签名和旧信笔迹不一致。沈家当众羞辱她、放出"疯前任纠缠"的热搜；答谢宴上苏曼丽偷偷塞给她房卡，房里留着一句"他不是我丈夫"。
**第8集反转**：她调出三年前那具无名男尸的档案，"左手虎口陈旧疤痕"——她解剖过的人，是她的未婚夫。

**第二段 验明正身（9–20）**
目标：证明死者是沈峥。私留切片做DNA，需要亲属样本；沈砚从敌对到偷偷交出头发。沈家起诉她诽谤，周启年封存旧档，样本库"意外"起火，她被停职。程野第一次深夜找她：我不知道他是怎么死的。
**第20集反转**：亲缘比对成立。可报告一公开，结论栏下就是她三年前签的"意外"，舆论翻转：她早就知道，她是共犯。

**第三段 签名的代价（21–32）**
目标：扳倒周启年。她拿出当年手写的"他杀"原稿，周启年反咬她伪造；她面临吊销资格。程野冒险偷出一页账本，证明周启年收过钱，那块金表就是收款当月买的。程野妹妹首次露面。
**第32集反转**：听证会上她不辩解，当众承认"字是我签的，我错了"，同时交出收款证据。周启年被带走前留下一句："钱不是沈家给的。"

**第四段 游艇之夜（33–46）**
目标：找凶手。先疑宋婉仪（是她找的替身），再疑沈砚（他在船上，却记不清）。苏曼丽为港口生意反水，把房卡当成"林晚威胁我"的证据交给沈家，林晚被带走调查。程野险些"意外"溺亡，林晚救下他，拿到替身合同。沈砚翻出那晚摔坏的旧手机。
**第45集**：修复的录音里只有争吵和一声闷响。
**第46集反转**：她把三年前的掌心照片和船锚袖扣对在一起，严丝合缝。宋知远就站在宋婉仪身后微笑。

**第五段 收网（47–60）**
宋知远出最后的狠招：烧游艇、让周启年翻供、扣住程野妹妹逼他交割。沈砚在火里抢出游艇工具箱，里面那套扳手唯独缺了一把。
**第50集**：交割仪式上，程野当众摘下手套："我不是沈峥。"
苏曼丽发现苏家也被拖进洗钱，交出港口账；宋婉仪看到掌心照片，才知道儿子是被杀的，崩溃后站到林晚这边，承认找过替身。
**法庭（56–59）**：辩方攻击"鉴定人签过假报告，不可信"。林晚回答：正因为签过，她最清楚错在哪。切片上的凹陷和同型号扳手对上，录音里的声音和宋知远对上。
**第60集**：宋知远认罪伏法，宋婉仪交出沈氏，程野带着妹妹去自首。林晚当庭推翻三年前的报告，写下"死者沈峥，他杀"并签名。最后一场，她把那块表放在沈峥墓前。

## 六、证据与反扑阶梯

| 段 | 核心证据 | 沈家反扑 |
|---|---|---|
| 一 | 疤、表、签名、房卡 | 当众羞辱、热搜抹黑 |
| 二 | 切片、头发、DNA报告 | 诽谤起诉、样本起火、停职 |
| 三 | 手写原稿、账本、金表 | 反咬伪造、吊销听证 |
| 四 | 替身合同、录音、袖扣 | 反水作证、拘查、灭口 |
| 五 | 港口账、扳手比对、证词 | 烧证、翻供、挟持人质 |

## 七、伏笔回收

- **表**：1 试探程野 → 60 放在墓前
- **虎口疤**：1 → 8 → 50 程野摘手套
- **船锚袖扣**：1 婚礼背景里出现 → 46 揭开
- **房卡**：5 求救 → 38 反水 → 54 回头
- **沈砚的醉**：12 他说"那晚我也在" → 45 录音
- **"钱不是沈家给的"**：32 → 46

## 八、AI拍摄约束

- 场景控制在七个：宴会厅、解剖室、法医中心、沈家老宅、游艇（只在回忆里）、法庭、墓园。
- 每个角色的视觉锚点全剧不变：灰风衣+旧表、白手套+金丝镜、黑耳钉、酒红指甲、老花镜+金表、旗袍+珍珠、船锚袖扣。
- 每集至少一个证据特写；回忆戏统一用冷蓝色调加海浪。
- 不拍群戏和打斗，冲突全靠对峙和特写。
