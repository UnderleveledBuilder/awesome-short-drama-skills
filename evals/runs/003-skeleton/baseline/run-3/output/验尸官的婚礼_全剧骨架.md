# 《验尸官的婚礼》全剧骨架

60 集竖屏｜每集 1–2 分钟｜AI 拍摄
本骨架约束后续分集大纲与剧本：真相、证据顺序、各段卡点不得改动。

## 一、底层真相（编剧全知，观众按顺序拿到）

1. 四年前，林晚与沈峥订婚。沈峥把自己戴了十年的旧机械表给了她。沈峥左手虎口有疤，是小时候替沈砚挡碎玻璃留下的。
2. 三年前，沈峥发现舅舅宋知远借海外港口洗钱。游艇上，宋知远用扳手砸他后脑，推入海中。沈砚醉倒在船舱，什么也没看见。
3. 尸体数日后漂回，面部损毁，作无名男尸由林晚主检。她写下“枕部生前钝器伤，他杀”。虎口那道疤让她心里一沉，可同一周她收到“沈峥”从国外发来的语音，说在养病——那是宋知远用旧录音拼的。周启年收了宋知远的钱，逼她改成“意外”并签字，三天内火化。她偷偷留下一块组织蜡块：违规，也是她放不下的东西。
4. 沈峥死前攥下宋知远一枚船锚袖扣。周启年把它从物证袋里拿走，连同受贿时偷录的通话，留作保命筹码。宋知远后来配了一枚新的。
5. 宋知远告诉姐姐：儿子醉酒落水。宋婉仪为保住长孙那一半股份，经弟弟找来程野整容顶替，以“养病归来”的沈峥露面。宋知远扣着程野的妹妹。
6. 一年前，宋知远怕法医近身看穿，让程野当众退婚。

## 二、引擎

- 明线问题：谁杀了沈峥？暗线问题：林晚敢不敢推翻自己签的字？
- 双轨：她每赢一次，真相进一格，她自己的罪证也进一格。前期沈家骂她“疯女人”，中期骂她“伪造证据”，后期骂她“出过假报告的法医”——攻击越来越准，因为越来越真。
- 每集公式：亮出一样能拍特写的证据 → 沈家毁证或抹黑 → 她用专业反打 → 尾钩落在下一样证据或一句新指控上。
- 林晚不抬声调、不动手、不靠男人救场，翻盘只靠证据和专业判断。

## 三、六段结构

**第一段 婚礼掀面（1–10）**
新郎摘手套戴戒指，虎口光洁。第 1 集结尾闪回解剖台上那只带疤的手。她当众说“你不是沈峥”，被架出去，视频被剪成“前任大闹婚礼”。她摘下新郎的金丝眼镜：平光镜。苏曼丽带头踩她，答谢宴上却塞来房卡，交出在丈夫书房找到的一叠签名练习纸，满纸“沈峥”。
卡点（10）：她调出三年前无名男尸档案照片，左手虎口，同一道疤。“沈峥三年前就死了。是我验的。”

**第二段 死人开口（11–22）**
她拿出私留的蜡块，切出切片，要沈砚的 DNA 比对。沈砚不信她，她说出那道疤是替他挡的，他给了血样。沈家反扑：法医中心档案室失火，蜡块被偷——她早已分装。比对结果：全同胞兄弟。宋婉仪关起门承认顶替，咬定儿子是落水意外，反咬她私留检材、结果无效。
卡点（22）：周启年当众拿出那份“意外”报告，签名是林晚。她被停职。

**第三段 谁砸了他的后脑（23–34）**
停职后她在体制外查。档案里的颅骨照片，凹陷形状对上游艇工具箱清单上少掉的那把扳手；声纹频谱证明那条“养病语音”是拼接的。暗处有人递出旧照片：那晚沈砚和哥哥在甲板争吵。沈砚终于承认自己在船上，他怕凶手是自己。她用伤口角度推出凶手比沈峥高，而沈砚比哥哥矮，洗清他。
卡点（34）：物证登记表原文写着“右手握金属饰物一枚”，物证袋是空的。经手人：周启年。

**第四段 主任的金表（35–44）**
金表购买日期是火化后第三天。苏曼丽为保苏家港口生意反水，把林晚的证据复印件交给沈家，并作证林晚威胁她。宋知远要让周启年“意外”，林晚抢先一步。周启年为活命交出袖扣和录音，当众被带走。
卡点（44）：录音里给钱的人笑着开口，是宋知远。

**第五段 舅舅（45–54）**
程野成了弃子，被安排一场“意外”；沈砚救出他妹妹，程野反水，交代整容、顶替和宋知远说过的每一句话。宋知远袖口两枚袖扣，一旧一新。苏曼丽见风向变，拿港口账本换苏家脱身，洗钱动机落地。宋婉仪听完录音，才知道儿子不是落水。
卡点（54）：宋婉仪站到林晚这边。宋知远的最后一招：申请排除林晚全部鉴定意见——“出过假报告的法医，她的话凭什么算数？”

**第六段 当庭（55–60）**
要让证据成立，她只能先推翻自己。她当庭讲出三年前如何被逼签字、私留检材，认下全部后果，重写结论：“死者沈峥，他杀。”签名。宋知远认罪伏法，宋婉仪交出沈氏，程野带着妹妹去自首。
第 60 集：墓园。她摘下那块表放在沈峥墓前，手腕上留下一道白痕。

## 四、人物弧线

- 林晚：从“认证据不认人”走到“连自己也认”。全剧唯一的成长，是把三年前的签名收回来。
- 沈砚：不信 → 怀疑自己 → 内应。“我在船上”是第三段的炸点，不得提前。
- 苏曼丽：踩她 → 求救 → 反水 → 再倒戈，每次都因为利益，不洗白。
- 程野：怕死的替身。转向只靠“宋知远要他死”和妹妹得救，不靠良心发现。
- 周启年：中段反派，第 44 集前倒台。
- 宋婉仪：以为在保儿子的家业，其实在替杀子凶手遮掩。崩溃放在 53–54 集。
- 宋知远：前 44 集是“最可靠的舅舅”，每次出场都在帮沈家“处理”麻烦，回看能对上他每一步。

## 五、铁律

1. 证据顺序固定：虎口疤 → 平光镜 → 签名练习纸 → 档案照片 → 蜡块 DNA → 颅骨照片与扳手 → 拼接语音 → 物证登记表 → 金表 → 袖扣与录音 → 程野证词 → 港口账本 → 她自己的签名。这 13 件是主证据，之间的集用小证据（伤痕、照片、记录单）填满，保证每集都有一样看得见的东西，但不得跳过或调换主证据。
2. 爽点只落在沈家与周启年脸上；林晚的代价（停职、违规留检材）不得被剧情轻轻抹掉。
3. 不写感情线。她对沈峥的感情只通过那块表表达：紧张时拧表冠。
4. 第 44 集前不得有角色说破宋知远是凶手，但每段至少埋一个回看能对上的细节（身高、袖扣、他总在毁证现场附近）。

## 六、AI 拍摄约束

- 场景锁定：婚礼宴会厅、解剖室、法医中心档案室/主任办公室、沈家老宅客厅、酒店房间、游艇甲板（仅回忆）、法庭、墓园。
- 人物造型全剧锁定，按选题卡执行；林晚的风衣和表不换。三年前的戏统一冷蓝色调，少对白。
- 每集不超过 2 个场景、4 个有台词角色；落水、火灾、“意外”只拍前后和特写，不拍过程。
- 每集至少一个证据物件的定格特写。
