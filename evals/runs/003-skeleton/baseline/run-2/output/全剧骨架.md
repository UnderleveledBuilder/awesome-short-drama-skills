# 《验尸官的婚礼》全剧骨架

60 集｜竖屏｜每集 1–2 分钟｜AI 拍摄

## 一、核心

- **明线**：三年前是谁杀了沈峥？
- **暗线**：林晚敢不敢推翻自己签过的那份假报告？
- **两条线终点相同**：抓到真凶的那一刻，就是她必须当众认错的那一刻。
- **发动机**：每集一件看得见的证据 → 沈家/周启年毁证或抹黑 → 林晚用专业细节反杀 → 离真相近一步，也离自己的签名近一步。

## 二、底层设定（全剧不得改）

1. **三年前**：沈峥在游艇上发现宋知远借港口洗钱，被扳手砸中后脑、推下海。几天后无名男尸上岸，面部被礁石和螺旋桨毁损。沈家对外说沈峥"出国养病"，林晚没往他身上想。
2. **假报告**：林晚初检写"他杀"（后脑凹陷骨折、肺内无溺液、硅藻阴性），被周启年逼着改成"意外"，签了字，三天火化。留下来的只有三样：法定留存的病理蜡块、她的私人工作笔记（含现场照片）、周启年私藏的证物袋。全剧证据都从这三处来。
3. **那道疤**：沈峥左手虎口的疤，是订婚前替林晚挡刀留下的，她亲手缝的。尸检记录里写着"左手虎口陈旧缝合疤"。
4. **替身**：宋婉仪以为儿子是落水死的，为保住遗嘱股份，由弟弟安排程野整容顶替。"沈峥"回国后说养病落下皮肤病，常年戴手套，对林晚冷淡；一年前当众退婚，是怕被她认出来。
5. **那块表**：订婚时沈峥从自己腕上摘给她的。表背刻着"收工，回家。——峥"，第 60 集才给特写。第 1 集她来婚礼，本来是想把表还给"沈峥"。
6. **倒计时**：沈峥 30 岁生日就是股份交割日（第 50 集）。程野签完字就没用了，宋知远会让他"意外"。

## 三、四幕结构

### 第一幕 婚礼（1–10）：认出替身

- **1**：交换戒指时新郎摘下手套，虎口光洁。林晚想起解剖台上那道她缝过的疤。集尾她开口："新郎三年前就死了。"
- **2–5**：沈家当众羞辱她"因爱生恨、发疯"。她拿细节一件件回击：新郎用右手敬酒（沈峥是左撇子），签名笔顺不对。周启年到场，以领导身份把她带走。
- **6–8**：回中心调三年前的档案，说是"已遗失"。她翻出私人笔记，原始结论写的是"他杀"。
- **9–10**：答谢宴上苏曼丽当众泼她酒，转身把房卡塞进她手里。林晚进婚房，发现新郎耳后有整容切口疤。【付费卡点】

### 第二幕 验明正身（11–30）：证明死者就是沈峥

- **11–15**：抢病理蜡块。周启年下令销毁"过期样本"，她截下最后一块。切片显示死后入水，是他杀。周启年把她调去夜班，书面警告。
- **16–20**：沈砚登场，处处敌视她。她用蜡块和沈砚做亲缘鉴定，结果兄弟关系成立。沈砚倒向她，成了她在沈家的内应（20）。
- **21–25**：沈砚偷出沈峥的旧指纹，和程野一比，不是同一个人。程野察觉，私下威胁林晚，却露出怕死的样子：他也在等自己那场"意外"。
- **26–29**：宋知远出场当和事佬，替林晚说话，劝姐姐给她补偿。这一段要让观众把他当好人。
- **30【中点】**：沈家家宴，林晚当面揭穿替身。宋婉仪平静承认："我知道。我儿子是落水，我只是替他守住东西。"周启年当场拿出那份报告：结论"意外"，签名林晚。她被自己的字堵住了嘴。

### 第三幕 坠落（31–45）：被自己的签名拖下水

- **31–34**：林晚停职，"法医造假""前未婚妻报复"上了热搜。她第一次亲口承认：字是我签的。只剩沈砚还信她。
- **35–37**：沈砚坦白那晚他也在游艇上，喝醉了，什么都记不得。苏曼丽交出新婚夜录音：程野说梦话，喊"别杀我"。
- **38**：苏曼丽反水。苏家的港口合同被宋知远卡住，她把蜡块交了出去，样本被毁。
- **39–42**：宋知远出手，游艇上搜出带沈砚指纹的扳手，沈砚被抓。林晚凭笔记里的颅骨骨折照片推算打击角度：凶手比死者高半头、右手抡击，和沈砚对不上。沈砚获释。
- **43–44**：程野遇上"车祸"，林晚在现场急救，把他救了回来。程野交出保命录音，里面宋知远对他说："别学你哥。"
- **45**：林晚放大笔记里的证物照片：死者右手攥着半枚银色船锚袖扣。镜头切到宋知远的袖口：一对船锚，其中一枚明显是新的。真凶锁定。

### 第四幕 清算（46–60）

- **46–49**：宋知远绑走程野的妹妹，逼他交割日照常签字。林晚把切片和颅骨照片摆到宋婉仪面前，母亲第一次知道儿子是被人杀的。
- **50【交割日】**：程野当众拒签，摘下手套。宋婉仪当众说出替身的事。
- **51–53**：苏曼丽回头，交出苏家手里的港口洗钱账目。周启年受贿被银行流水坐实，为求减刑交出私藏的证物袋（照片里那半枚袖扣、死者指甲样本），交出时反咬一句："林晚也签了字。"
- **54–56**：宋知远逃上那艘游艇。沈砚在船上想起了那晚的声音。指甲缝皮屑 DNA 比对结果是宋知远。人被抓获，程野妹妹获救。
- **57–59**：庭审。辩方攻击林晚三年前作过假，整条证据链不可信。林晚当庭承认自己签过假报告，推翻它，重新写下"死者沈峥，他杀"，签上自己的名字。宋知远认罪，宋婉仪交出沈氏，程野带着妹妹去自首。
- **60**：墓园。林晚把表放在沈峥墓前，表背刻字特写。表终于还给了真正的沈峥。

## 四、人物弧线与转折集

| 人物 | 弧线 | 转折集 |
|---|---|---|
| 林晚 | 认证据不认人 → 连自己也认 | 8 看到原始笔记；30 被签名封口；33 首次承认；58 当庭签名 |
| 沈砚 | 不信 → 内应 → 被陷害 → 记起 | 20 / 40 / 55 |
| 苏曼丽 | 踩人 → 求救 → 反水 → 回头 | 10 / 36 / 38 / 51 |
| 程野 | 威胁 → 怕死 → 被救 → 拒签 → 自首 | 23 / 43 / 50 / 59 |
| 宋婉仪 | 守股份 → 认替身 → 知真相 → 交权 | 30 / 49 / 59 |
| 周启年 | 压人 → 反杀 → 落网反咬 | 5–15 / 30 / 53 |
| 宋知远 | 好人 → 暗手 → 揭穿 → 伏法 | 26 / 38–42 / 45 / 56 |

**打脸账本**：沈家挨打在 2–5、10、20、50、59；周启年挨打在 8、15、53；第 30 集反过来让林晚挨一次狠的。

## 五、写作铁律（分集大纲、剧本必须遵守）

1. 每集必须有一件能拍特写的实物证据或证据进展：疤、切片、照片、录音、指纹、袖扣。不准用"她推理出来"顶替实物。
2. 每集沈家或周启年必须有一个动作：毁证、抹黑、收买、威胁，四选一。
3. 林晚不抬声调、不哭闹，靠专业细节赢。吵架戏让对手嗓门高。
4. 每个大节点（8、30、33、53、58）都要回到"她签过字"，暗线不能断。
5. 宋知远在第 45 集前不能有任何让观众直接锁定他的镜头。船锚袖扣在 1–44 集要反复入画，但不给特写。
6. 林晚不加新感情线，她和沈砚只是盟友。
7. 集尾必须留钩子：新证据露头，或证据被毁。
8. 程野在 1–49 集全程戴白手套，第 50 集摘下后不再戴。

## 六、AI 拍摄约束

- **主场景不超过 8 个**：婚礼宴会厅/婚房、解剖室、档案室、沈家老宅餐厅、游艇、医院、法庭、墓园。
- **人物造型锁死**，照人物卡执行，全剧不换。识别锚点：林晚的灰风衣和旧表，程野的金丝眼镜和白手套，沈砚的黑耳钉，苏曼丽的酒红指甲，周启年的金表，宋婉仪的珍珠耳环，宋知远的船锚袖扣。
- 证据特写统一用竖屏大特写，单镜不超过 3 秒，配一句台词点明它证明了什么。
