# 《验尸官的婚礼》全剧骨架

60集｜竖屏｜每集1–2分钟｜AI拍摄

## 一、底层真相（全剧不得违背）

- **四年前**：林晚与沈峥订婚。沈峥把自己戴旧的机械表给她："看尸体的时候看时间。"沈峥左手虎口有一道旧疤，是少年时替沈砚挡碎玻璃留下的。
- **三年前·游艇夜**：沈峥查到舅舅宋知远借海外港口洗钱，当面摊牌。宋知远用扳手砸他后脑，推下海。沈峥挣扎时扯下宋知远一枚船锚袖扣，攥在手里。沈砚醉倒在舱内，只记得一声闷响和一个高个子背影。
- **次日**：宋知远告诉姐姐，沈峥醉酒落水，尸体没找到。宋婉仪为保住遗嘱股份，对外称长子出国养病，由宋知远找来程野整容顶替。
- **十天后**：海上浮起一具面部被螺旋桨毁损的无名男尸，送到林晚的解剖台上。那时沈家说沈峥在国外，还在给她发消息。她写下"后枕部钝器伤，他杀"，并记录"左手虎口陈旧疤痕""右手握金属异物"。周启年收了宋知远的钱，把结论改成"意外落水"，拿走异物，逼她签字，三天内火化。林晚违规私留了一套组织切片，这就是她心里那根刺。周启年把袖扣锁进自己的保险柜，留着拿捏宋知远。
- **之后两年**：程野借"养病后性情大变"疏远林晚，一年前当众退婚：他最怕法医离他太近。

## 二、主线与引擎

- **明线**：林晚要一步步证明三件事：新郎是假的；台上那具尸体是沈峥；凶手是谁。
- **暗线**：她每往前一步，都更靠近自己签的那份"意外"报告。终点不是抓人，是她当众推翻自己。
- **单集三件套（每集必备）**：
  1. 一件看得见、能特写的证据（疤、表、签名、牙片、切片、录音、袖扣……）；
  2. 沈家或周启年反扑一次：毁证、栽赃、舆论抹黑、停职、威胁；
  3. 结尾钩子：要么新证据露头，要么林晚被推进更深的坑。
- **节奏**：每3集一次小翻盘，每10集左右一次大反转。

## 三、五幕结构

### 第一幕 婚礼（1–10集）：她认出来了
- **1集**：林晚作为前未婚妻被请来"看笑话"。新郎摘白手套戴戒指时，虎口光洁。闪回解剖台：同一个位置有疤。片尾她看着腕上的表："他三年前就死了。"
- **2–6集**：她当众试探：表认不出、旧称呼答不上，程野露馅。沈家反咬她被退婚后发疯、"摸死人摸出了毛病"，视频冲上热搜。苏曼丽带头踩她。
- **7–9集**：周启年（金表特写）以"精神状态"为由让她停职。沈砚冷眼旁观，却被她一句"你哥虎口那道疤是替谁挡的"刺中。
- **10集（付费卡点）**：答谢宴上，苏曼丽当众泼她酒，转身塞给她一张房卡，背面写着："他不是我丈夫，救我。"

### 第二幕 替身（11–22集）：证明新郎是假的
- **证据梯度**：签名笔压→旧牙片对不上→声纹→沈砚偷来新郎的毛发，与自己做亲缘鉴定。
- **反扑**：牙科档案被烧，鉴定所被收买，林晚被反告诽谤。
- **程野线**：他开始害怕，深夜给林晚打无声电话；他妹妹被宋家安排进一家疗养院"住院"。
- **18集**：沈砚说出"那晚游艇上我也在"，成为内应。
- **22集反转**：亲缘报告证明新郎和沈砚没有血缘。林晚拿着报告去找宋婉仪，宋婉仪平静地说："我知道。"顶替是母亲亲手安排的。

### 第三幕 尸体（23–35集）：台上那个人就是沈峥
- 林晚拿出私藏三年的切片，和沈砚的DNA比对。这是她第一次动自己的刺：拿出切片，就等于承认当年违规留样、知情签字。
- **反扑**：周启年伪造当年尸体的家属认领记录；苏家放出旧照，说林晚为钱缠上沈家。
- **30集（中点大反转）**：比对成立，死者是沈峥。宋婉仪崩溃，她一直以为儿子只是落水、尸体没找到。同一集，周启年在发布会上亮出那份"意外"报告："结论是她亲手签的。"林晚从揭发者变成被调查的人。
- **31–35集**：她被立案，众叛亲离。程野私下找她：有人在给他安排"意外"了。

### 第四幕 凶手（36–48集）：谁砸了那一下
- 后枕伤口形状指向扳手；沈砚的记忆拼出高个子背影和袖口一点银光（37集），呼应第1集宋知远的袖扣。
- **40集**：苏曼丽反水。苏家港口生意被宋知远捏住，她把林晚的证据备份交了出去，沈砚因此被打进医院。
- **42–45集**：林晚设局，让周启年以为宋知远要灭口。周启年手里一直留着保命录音：宋知远付钱，要求"三天内火化"。金表、账户、录音同时摊开，周启年被当场带走（45集）。
- **46–48集**：周启年的保险柜里起出那枚船锚袖扣，上面带着三年前的锈。宋知远腕上那一对，是事后补配的新货。林晚和沈砚把程野的妹妹从疗养院带出来。

### 第五幕 庭审（49–60集）：她推翻自己
- **49–54集**：宋知远最后反扑，把罪推给死去的沈峥"挪用公款"，并拿林晚签的报告当辩护证据：法医自己说是意外。苏曼丽交回宋知远洗钱的港口单据，第二次转向，但不洗白。
- **55集**：宋婉仪得知是弟弟杀了儿子，当着宋知远的面，第一次不再轻声细语。
- **56–57集**：程野出庭，讲出替身的全过程；伤口对上扳手，袖扣对上宋知远，加上切片和录音。但辩方仍咬住"法医结论是意外"。
- **58集（全剧高潮）**：林晚当庭陈述："三年前那份报告是我签的，是假的。"她重新写下"死者沈峥，他杀"，签上自己的名字。宋知远最后一道防线塌了。
- **59集**：宋知远认罪伏法；宋婉仪交出沈氏；程野带妹妹去自首；林晚接受处分。
- **60集**：墓园。林晚把那块表放在沈峥墓前，表针还在走。

## 四、人物弧光

- **林晚**：藏着刺→亲手拔刺。前半部用证据审别人，后半部审自己。
- **程野**：活着的道具→说出真相的证人。底线是他从没害过人，只是怕死。
- **沈砚**：没人信的弟弟→替哥哥讨公道的人。他的"记不清"必须在第四幕补完。
- **苏曼丽**：踩人→求救→反水→交单据。可以自私，但每次转向都要有利益原因。
- **宋婉仪**：为股份顶替儿子→为儿子交出股份。她不是凶手，但不能太快被原谅。
- **周启年**：拿权力压人→被自己留的把柄反咬。
- **宋知远**：最终对手。前40集只能是"最可靠的舅舅"，不得提前露凶相。

## 五、爽点分配

- **沈家**：2–6集新郎露馅，22集主母被戳穿，30集主母崩溃，55集母亲与舅舅反目。
- **苏曼丽**：前期踩人被林晚当场驳回，40集反水后被宋知远当弃子，49集低头。
- **周启年**：9集停职（压）→30集发布会（压）→45集当场带走（打）。
- **宋知远**：56–59集一层层剥掉他的和气。
- **原则**：爽点来自证据，不来自吵架。

## 七、AI拍摄约束

- **外形锁死**：林晚短发、灰风衣、旧表；程野金丝眼镜、白手套；沈砚寸头、黑耳钉、西装不扣；苏曼丽全妆、酒红指甲；周启年老花镜、金表；宋婉仪旗袍、珍珠；宋知远船锚袖扣。服装只在关键节点变化。
- **主场景不超过8个**：婚礼厅、解剖室、法医中心办公室、沈宅客厅、酒店套房、疗养院、法庭、墓园。游艇只用于闪回，冷蓝夜色，碎片化处理。
- 每集至少一个证据实物特写；少群戏、少打斗，冲突靠对视、递东西、念报告。
