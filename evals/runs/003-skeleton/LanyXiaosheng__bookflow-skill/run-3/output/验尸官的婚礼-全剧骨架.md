# 《验尸官的婚礼》全剧骨架

> 60 集竖屏 · 每集 1–2 分钟 · AI 拍摄。分集大纲和剧本都按本文件写；要改走向，先改这里，再往下写。

## 一、核心

- **主线问题**：三年前是谁杀了沈峥？
- **暗线问题**：林晚敢不敢推翻自己签过的“意外”？
- **单集发动机**：每集一件看得见的证据，固定三拍：林晚亮证据 → 沈家 / 周启年毁证或抹黑 → 林晚靠专业反杀，多拿一块真相。每赢一次，离凶手近一步，也离自己的签名近一步。
- **情绪曲线**：屈辱 → 痛快 → 自我审判 → 清算 → 释然。
- **故事时间**：约 30 天，从婚礼到股权交割日。

## 二、设定校准（骨架补充，已锁定）

- **三年前**：沈峥查到舅舅宋知远借港口洗钱。出海前一晚，他把自己的旧表留给林晚，说“回来再拿”。游艇上他被扳手砸了后脑，推下海。尸体泡了多日，面部损毁，以无名男尸送上林晚的台子。她记下“后脑钝器伤、左手虎口陈旧疤痕、右手攥金属残片一枚（海水磨损，形状不明）”，判他杀；周启年逼她改成“意外”，三天后火化，残片封进证物室。
- 宋知远告诉姐姐：沈峥醉酒落水，尸体没找到。宋婉仪为保股份找程野顶替，对外说“国外养病”。程野回国后一直躲着林晚，一年前当众退婚。林晚从没把那具无名尸和未婚夫联系起来。宋知远常驻海外，林晚很少见他。
- **虎口疤**：沈峥小时候替沈砚挡碎玻璃留下的，沈砚认得这道疤。
- **倒计时**：婚礼后第 30 天是沈峥三十岁生日，也是股权交割日。交割一完，程野就没用了。
- 程野的妹妹由宋知远“照顾”，是程野的软肋，第 15 集前必须出场。

## 三、四幕走向

### 第一幕 婚礼（1–10）：她认出来了

- **1**：沈家发请柬羞辱她，她来了。交换戒指时新郎摘下白手套，虎口光洁。她想起解剖台上那道疤。钩子：她站起来说“这个人不是沈峥”。
- **2–6**：她被当成疯前任拖出去，宋婉仪当众羞辱她，周启年以“情绪不稳”停了她的职。她拿耳廓形状对比照、签名的收笔，一处处戳破替身。
- **7–9**：沈砚嘲讽她，被她一句“你哥虎口那道疤是替谁挡的”问住。
- **10**：答谢宴上苏曼丽当众泼她酒，转身把房卡塞进她手里，背面写着“救我”。【卡点】

### 第二幕 尸体（11–30）：证明台上那人是沈峥

- **11–15**：苏曼丽交出新婚夜录音：丈夫说梦话，喊的是另一个名字。程野的赌债和整容记录浮出来，妹妹出场。
- **16–20**：林晚找回当年的原始记录底稿，被周启年当面撕碎，可她早拍了照。档案室里还留着当年的病理切片。
- **21–25**：沈砚交出自己的头发，林晚托第三方实验室拿切片做 DNA 比对，结果是亲兄弟。沈砚崩溃，成了她在沈家的内应。
- **26–29**：沈家抢切片、烧档案室，网上骂她“恋尸法医”。她当众讲解剖结论反击，舆论翻转。
- **30（中点反转）**：沈家密室里，宋婉仪承认儿子三年前就没了，替身是她找的：“可我儿子是落水，是意外。不信？报告上是你签的字。”周启年把那份签名拍在桌上。【卡点】

### 第三幕 签名（31–45）：从“他是谁”到“谁杀了他”

- **31–34**：周启年告她私取切片、泄露档案，林晚被立案调查，比对结果在程序上作废。她不辩解，只追问一件事：当年让我改结论的钱是谁给的。
- **35–37**：后脑骨折照片对上扳手形状，线索指向游艇。沈砚终于说出那晚他也在船上，喝醉了，只听见哥哥跟人吵：“港口的账你别碰。”嫌疑落到同做港口生意的苏家。
- **38–40**：林晚查苏家，宋知远趁机捏住苏家生意。苏曼丽反水，把录音原件交了出去，林晚手里只剩当不了证据的翻录件，线断了。
- **41–44**：林晚放风说程野要自首。周启年赶去证物室销毁那块金属残片，被当场拍下；金表来历和转账记录一起落地。残片洗净后是半枚船锚袖扣。被带走前，周启年喊出了宋知远的名字。
- **45**：一直温和帮忙的舅舅宋知远登门，袖口那对船锚袖扣一新一旧。钩子：他笑着问“你那块表，还走得准吗？”【卡点】

### 第四幕 清算（46–60）：她亲手推翻自己

- **46–50**：交割日逼近，程野发现交割后自己会被安排“出海”。林晚救下他，代价是沈砚暴露。程野为了妹妹倒戈，交出三年来宋知远给他的指令。
- **51–53**：旧表停了。林晚拆开后盖，找到沈峥藏的存储卡，里面是港口洗钱账，杀人动机落地。
- **54–55**：宋知远对苏家下手，苏曼丽发现自己是下一个“意外”，带着港口账第二次倒戈。
- **56**：交割日股东会，就开在婚礼那间宴会厅。宋婉仪看完证据，才知道儿子是被亲弟弟杀的。她当众承认替身，交出沈氏。
- **57–59**：庭审。宋知远拿林晚的旧签名攻击她的证词。林晚当庭承认三年前签的是假报告，愿意担责，然后逐条讲出死者身上的伤。宋知远认罪伏法，程野带妹妹自首。
- **60**：林晚在当年那份报告的更正栏里写下“死者沈峥，他杀”，签上自己的名字。墓园里，她给那块表上满弦，放在沈峥墓前。

## 五、爽点账本（先压她，再还回去）

- **周启年**：3 停她职 → 18 撕底稿被拍 → 30 拿签名压她 → 44 当场被抓。
- **宋婉仪**：6 当众羞辱 → 30 拿签名压她 → 56 当众认替身、交出沈氏。
- **程野**：1 摘手套穿帮 → 5 签名穿帮 → 47 被抛弃，求林晚救命。
- **苏曼丽**：10 泼酒 → 40 反水 → 55 回头求她。
- **宋知远**：45 露面 → 59 认罪。

## 六、写作铁律

1. 每集只出一件主证据，必须是能拍特写的实物、画面或声音。
2. 证据不能白毁：每毁一次，林晚必须有备份，或者从毁证的动作里拿到新证据。
3. 破案和反杀都归林晚。沈砚、苏曼丽、程野只递线索，不替她下判断。
4. 林晚不哭不吼，不抬声调，一句专业判断就收住。
5. 第 45 集前宋知远只当“好舅舅”；袖扣只给观众看，最多两次特写（12、36），林晚不能注意到。
6. 林晚的代价不能洗白：第 59 集她必须认签字、认责任。
7. 解剖画面不拍血腥特写，用报告、照片轮廓、器械声代替。
8. 每集开头 3 秒接上集钩子，结尾必须留新钩子。

## 七、AI 拍摄约束

- **造型锚点每集不变**：林晚短发、灰风衣、旧表；程野金丝眼镜、白手套；沈砚寸头、黑耳钉、西装不扣；苏曼丽全妆、酒红指甲；周启年花白背头、金表；宋婉仪旗袍、珍珠耳环；宋知远船锚袖扣。
- **主场景不超过 8 个**：婚宴厅、酒店房间、解剖室 / 档案室、沈家客厅、游艇（只用于回忆）、医院、法庭、墓园。
- 每集最多 3 场戏、4 个说话人；回忆统一冷蓝色调。
- 关键道具先做道具卡：虎口疤、旧表、房卡、切片、金属残片 / 船锚袖扣、扳手照片、存储卡。
