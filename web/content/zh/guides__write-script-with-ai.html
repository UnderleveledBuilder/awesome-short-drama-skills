先给 agent 装一个实测赢过的剧本 skill 再写，稿子比直接让 AI 写更适合上屏；但挑方向、改人名、删元数据这三步要你自己来。下面的做法来自我们的第一轮实测：10 个剧本 skill 和 1 个不装 skill 的对照组，用同一个模型、同一份需求各写 3 次，共 33 部剧，由两位 AI 评审匿名盲比。

1. 装一个实测赢过的剧本 skill

skill 是装进 agent 的一套写作方法和模板，见什么是短剧 skill。但装了不一定就好：10 个里只有 4 个三次都赢了对照组，两位评审意见一致；另外 6 个，两位评审分歧很大。

  • 剧本和人物大纲都三次全赢：drama-skills、山音编剧大师、screenwriting-skills、艾玛编剧。
  • 人物大纲三次全赢：ai-short-drama。

装法见安装指南，最快的是 npx skills add 作者/仓库名。这些结论只在 claude-opus-5-5 上测过，换模型可能不同。

2. 需求只写篇幅和交付物

实测用的需求只有几行，不给题材、人物和情节，这些 skill 照样能写完：

写一部竖屏短剧。
- 篇幅：全剧 60 集，每集 1–2 分钟
- 交付（写成文件，放在当前目录）：
  1. 主要人物小传
  2. 60 集分集大纲，标出付费卡点
  3. 第 1–3 集完整剧本

存成 premise.md，对 agent 说「我要写一部短剧，要求在 premise.md 里」。心里已经有题材和人物，就加进去。实测里，一次从需求写到三项交付用了 9 到 35 分钟。

3. 先让它给几个方向，你来挑

33 次运行里，只有漫剧老李、山音编剧大师和 shuohao 的个别几次停下来给出几个故事方案，其余都是自己定一个就写到底。skill 还会把故事往固定的方向带：同一个 skill 的两次运行，落进同一种故事类型的比例是 12%，不同 skill 之间只有 2.4%。比如 hongguo 三次写的都是全职儿媳清算婆家。

所以开头加一句：「先给我 3 个题材和主角都不一样的故事方案，每个一句话卖点，等我选了再往下写。」一个 skill 总写同一类故事，可以换一个试试。

4. 改掉模型默认的人名和设定

不管装哪个 skill，模型自己的习惯都还在：33 份稿子里有 15 份出现了叫「小满」的角色，10 份的女主姓沈；zenstory 和 shuohao 各写了一部《掌眼》，女主都是同一家虚构拍卖行的首席鉴定师。用同一个模型的人很多，不改的话，你的剧容易和别人撞名、撞设定。

写完把人名全文搜一遍，换成你自己起的；开场和设定也问一句：换个名字，这是不是最常见的那一类故事？

5. 按「上屏」检查每一集

评审假定稿子要交给 AI 从头拍成片：没有演员和片场，画面、声音、口型都由视频模型生成。赢了的 skill 赢在下面几处，检查时照着看：

  • 每集装得进 1–2 分钟，按画面和台词估。对照组输在每集塞得太多，常明显超过 2 分钟。
  • 情绪落在脸上、动作和物件上，不靠心里话和旁白。比如 screenwriting-skills 的一份稿子里，不能说话的妻子在结婚纪念日给丈夫怀孕的情人盛汤，只写了一句「汤面一丝都没晃」。对照组的关键推理常靠 OS 讲出来。
  • 台词短，每个人物说话的口气不一样。「笑意不达眼底」「声音冷得像冰」这类套话越少越好。

特效、异能、大场面、群戏、场景多、角色多，都不算缺点：交给 AI 拍，这些不额外花钱。但场面大也不等于好看，要落在人物和爽点上才算数。

6. 集尾钩子和付费卡点，自己再盯一遍

这两项 skill 没有明显优势。付费卡点上，主评审的 60 次判断里对照组赢了 34 次，skill 只赢 11 次。33 份稿子的第一个付费卡点全在第 10 集，这是行业惯例，也是模型的默认选择。集尾钩子两位评审看法相反：Opus 认为对照组更强，GPT 认为 skill 更强。

所以每集最后一场单独读一遍，问自己想不想点下一集。卡点那一集的结尾要够狠，比如对照组第 10 集的首个卡点，女主刚赢下一局，就收到一条短信：「爸爸今晚三点会停止呼吸。不是意外。」

7. 交给 AI 出片前，删掉稿子里的元数据

每个 skill 的稿子里都夹着编号、时长预估、检查点、自检表、模板标签，比如「预估 90.8 秒」「Continuation Capsule」「【本集结算】」。主评审比了 120 场，有 110 场在理由里提到这些要删掉才能用。让 agent 另存一份只有场景、动作和台词的干净版，再拿去做分镜和视频提示词。

这些结论能说明什么

  • 只测了一个模型，claude-opus-5-5，换模型可能不同。
  • 评审是 AI。换 GPT 用一字不差的提示词重判，60 对结果里 39 对一致，所以第 1 步推荐的 skill 只写了两位评审都同意的。
  • 比的是稿子，还没有交给 AI 拍成片。

每次运行的全部输入、每一步过程和每场判决，都公开在第一轮实测记录里，可以自己核对。
